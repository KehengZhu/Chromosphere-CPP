# 这个项目在做什么 —— 中文说明

**写于 2026-09-06。** 这是一份**解释性**文档，用尽量简单的语言说清楚三件事：Igor Sokolov 的
AWSoM-R 是什么、它在色球这一块留了什么口子、我们要交付什么东西去补这个口子。

**它不是计划文档。** 所有规划、排期、风险和取舍以 `publication_strategy_plan.md` 为准；那份是
英文的、决策导向的。这一份只负责让人看懂。代码行为以当前源码为准。

文中所有数字都标了出处。**凡是"实测"的，指从本仓库的 release 跑或代码里直接量出来的；凡是
"文献"的，指从原始 PDF 逐字核对过的。**

## 0. 一句话

> 太阳大气从下到上分成光球、色球、过渡区、日冕。Sokolov 的全球日冕模型算不动最底下那一小段，
> 于是把它切掉、接了一个公式，并在接口上钉了一个人为放大十倍的密度当作"无限的物质来源"。
> **我们做一根真实的一维色球柱子，先量那个公式的几条假设各偏多少（第一批，现在的域就能做），
> 再把域往上延伸、交出一个修正版的公式（第二批，几个月后）。**

**两批的区别很重要，别混**（详见第 6 节）：第一批里域顶的压强是**输入**，我们在积分区间的
**下面**做审计；第二批域延伸之后，压强才变成**输出**。

## 1. Igor Sokolov 在做什么

### 1.1 需求：太阳风预报要快

太阳会往外吹带电粒子（太阳风），偶尔还会甩出巨大的等离子体团（CME）。这些东西撞到地球会
干扰卫星、电网、导航。要预警，就得**在事情发生之前算完**——预报比现实慢就没有意义。

Sokolov 在密歇根大学，他的模型叫 **AWSoM**（Alfvén Wave Solar atmosphere Model），
后来的版本叫 **AWSoM-R**，那个 **R 是 realtime**（实时）——**名字本身就是设计目标**。

### 1.2 他的物理：用 Alfvén 波加热日冕

日冕比太阳表面热两百倍（表面 6000 K，日冕 100 万 K）。为什么？这是太阳物理的老问题。

AWSoM 的答案是：**磁场里的 Alfvén 波**。太阳表面的对流不停地抖动磁力线，抖动沿磁力线往上传，
在上面变成湍流耗散掉，把日冕加热、把太阳风加速。

> 类比：抖一根绳子，波往上跑，在上面散掉、把绳子搓热。

AWSoM 把这套写成方程，一路从色球顶算到地球轨道以外。

### 1.3 瓶颈：过渡区

问题出在**过渡区**——色球（约 6000 K）和日冕（约 100 万 K）之间那一层。

温度在**几百公里**之内涨两个数量级，梯度约 **10⁴ K/km**。要在三维网格上把它算准，格子得压到
公里以下。而这一层还得解隐式的电子热传导。

Sokolov 自己的话（2021 论文）：

> "the greatest number of computational resources is spent in maintaining the numerical solution in
> the low SC and in the transition region... **the low SC appears to be a bottleneck limiting the
> computational efficiency and performance.**"

**整个模型的计算量卡在最底下那薄薄一层。**

### 1.4 他的办法：thread（磁力线束）

AWSoM-R 的做法很聪明：**把最底下那一层从三维网格里拿掉。**

理由是：在那一层磁场很强，等离子体只能**沿着磁力线**流动、热量也只能沿磁力线传。

> 类比：**磁力线像一根根管子**，气体只能在管子里上下走，不能横穿。

既然如此，就不用解三维，只要**沿每根管子解一维**就够了。

于是：从三维网格底面的**每一个格点**往下描一根磁力线，叫一条 **thread**，每条 thread 上解一维
方程，算完再把结果交回三维模型。这就是 **TFLM**（Threaded Field Line Model）。

**结果：在约 200 个核上跑得比实时还快。** 这是很大的成就。

> **顺带一个重要的点：一维近似不是我们要辩护的，是我们继承的。** Sokolov 自己就是这么论证的，
> 我们只是在同一个近似上再往下走一层。

## 2. 口子在哪：thread 的下端怎么收尾

这一节是整个项目的核心。慢一点讲。

### 2.1 先分清三个高度

大部分混乱来自把三个不同的高度当成同一个。它们从上到下是：

```
  温度        高度(C7层结)     AWSoM-R 怎么处理              我们的柱子
 ─────────────────────────────────────────────────────────────────────────
  ~1 MK     1.01–1.1 R☉   ══╤══  R_b：交回三维 MHD 模型
                             │
                             │    thread —— 一维数值求解
                             │    （全电离 + Spitzer 传导 + 光学薄辐射）
                             │
  ~4×10⁵ K    ~3.15 Mm   ────┼──  T_TR ← 数值 thread 的下端
                             ┊
                             ┊    ★ 解析公式 Eq.19–22 管这一段
                             ┊      厚度 L_TR ≈ 1 Mm，直接规定
                             ┊
  1–2×10⁴K  2146–2152 km ────┼──  T_ch ← 公式的下端      ┬── 域顶 2153 km, 22 kK
                             ╳                           │
                             ╳    什么都没有              │   真实的一维色球柱
                             ╳    （底下钉一个固定密度     │   Saha 电离 + 物理传导
                             ╳      的水库顶着，见第3节）  │
  6631 K      1600 km        ╳                           ┴── 域底 1600 km
```

三个名字，记住就不会乱：

- **`R_b`** —— thread 的**上**端。到这里就交回三维模型。
- **`T_TR`** —— **数值** thread 的**下**端。再往下就不数值求解了。
- **`T_ch`** —— **解析公式**的下端，约 1~2 万 K，名义上叫"色球顶"。**再往下什么都没有。**

`T_TR` 和 `T_ch` 之间那一段，就是被那个解析公式代替掉的部分，厚度 `L_TR ≈ 1 Mm` 是**规定**的。

**`T_ch` 以下就是口子。**

### 2.2 为什么 thread 不能一直往下解

一个自然的疑问：既然 thread 已经是一维的了，很便宜，为什么不干脆一路解到光球？

**不是因为贵，是因为 thread 自己的方程在下面就不成立了。** thread 的方程假定了三件事：

1. 气体**全电离**，理想气体，`γ = 5/3`
2. 热传导是 **Spitzer** 的（`κ ∝ T^{5/2}`，电子导热）
3. 辐射是**光学薄**的（光子发出来就直接跑掉）

这三条在日冕里都对。**在色球里三条全错**：

1. 6600 K 处氢只电离了约 27%（实测），大量中性氢；`γ` 也不是 5/3
2. 中性气体主导时电子热导不是主角
3. 色球是**光学厚**的——光子发出来会被别的氢原子吸收，再发射，跑不掉

要往下解就得换一套东西：Saha/部分电离状态方程、光学厚辐射转移、更细的网格。**那是另一个代码。**

> **所以 AWSoM-R 停在这里不是偷懒，是它的物理到此为止。**
> 而"另一个代码"正是我们在做的东西。

### 2.3 那个公式在做什么 —— 一步一步

**第一步：写下过渡区的能量平衡。**

在稳态的过渡区里，只有两件事在发生：

- 上面的日冕很热，热量沿磁力线**传导**下来
- 传下来的热被**辐射**掉（变成光子跑掉）

稳态就是这两件正好抵消。写成公式（论文 Eq. 19）：

```
 −∂/∂s ( κ₀ T^{5/2} · ∂T/∂s )  =  − N_e N_i Λ_R(T)
        ↑                              ↑
   传导热流沿路径的变化               辐射损失
```

`κ₀T^{5/2}` 是热导率——注意对温度是 **2.5 次方**，极其敏感。`Λ_R(T)` 是辐射损失函数，
从 CHIANTI 原子数据库查表来。

**第二步：把"空间"消掉。这是最关键的一步。**

上面那个方程直接解，就得知道每个高度 `s` 上的温度——那又回到"要极细网格"的老问题，
等于白干。

Sokolov 的做法：两边同乘 `∂T/∂s`，然后**对温度积分**。这一步做完，**`s` 消失了**，
方程变成热流和温度之间的一个代数关系（Eq. 20）：

```
½ κ₀² T⁵ (∂T/∂s)²  =  {N_i T}² × ∫[从 T_ch 到 T] κ₀T₁^{1/2}Λ_R(T₁) dT₁
```

> **翻译：不用再问"在哪个高度"，只要问"在哪个温度"。**

**这就是整个方法便宜的原因**——空间没了，剩下的是纯粹关于温度的积分，**可以预先算好、做成一张表**。
论文的 Figure 1 就是那张表。每条 thread 每一步只是**查表**。

**第三步：把常数拉出积分号——两个假设藏在这里。**

看上式右边的 `{N_i T}²`。它是把 `N_i T`（正比于压强）当成常数、从积分里拉出来的结果。
理由是过渡区太薄，重力来不及起作用，压强来不及变。

这一步同时藏进了**两个**假设：

- **压强恒定**（假设 2）
- `N_e N_i` 被写成了 `(N_i)²` —— 这要求 **电子数 = 离子数 = 总氢原子数**，也就是**氢全电离**（假设 6）

**第四步：出结果。**

给定过渡区厚度 `L_TR` 和顶部温度 `T_TR`，Eq. 21 给出压强，Eq. 22 给出热流：

```
Eq.21:  {N_i k_B T} = (1/L_TR) ∫[T_ch → T_TR] κ₀T^{5/2} / U_heat(T) dT
Eq.22:  热流 = {N_i k_B T} × U_heat(T_TR)
```

其中 `U_heat(T)` 是一个有速度量纲的量，本身也是一个**从 `T_ch` 积起**的积分。

**注意 `T_ch` 出现在两个积分的下限上。这是第 8 节 ③ 那个"旋钮"问题的来源。**

### 2.4 为什么这个办法聪明

值得说清楚，因为这决定了我们该怎么写论文——**这是个好方法，我们是在补它的边界，不是在推翻它。**

背后的物理洞察是：过渡区**又薄又陡**，所以

- **薄** → 重力没有空间起作用 → 压强基本恒定
- **陡** → 传导和辐射压倒其他一切 → 只剩两项要平衡

在这两个条件下，过渡区变成一个**局域的、普适的**结构：它长什么样只取决于压强和温度范围，
**跟它在哪儿、周围有什么无关**。

> **既然普适，就可以算一次、做成表，所有 thread 共用。**
>
> 这就是为什么 AWSoM-R 能"比实时还快"。

### 2.5 它输出的是一种奇怪的边界条件

通常的边界条件是两种之一：

- **给定温度**："这里是 50,000 K"（Dirichlet）
- **给定梯度**："这里的温度梯度是多少"（Neumann）

但 Eq. 21–22 给的**都不是**。它给的是 **温度和梯度之间的一个关系式**——你自己去找同时满足
这个关系、又能接上上面数值解的那个组合。

Sokolov 自己的话：

> "the BCs, which set **neither temperature nor its gradient, but which relate the temperature and
> its gradient** at the boundary" ——他说这"unusual but mathematically legitimate"（不常见，
> 但数学上合法）。

> 类比：不是告诉你"门开 30 度"，也不是告诉你"用 5 牛顿推"，而是告诉你
> **"开的角度和推的力之间是这个关系"**，剩下的你自己配。

### 2.6 八个假设，逐条

前面推导里已经出现了几个。完整列一遍，每条都说清楚：**是什么 / 为什么要这么假设 /
在 `T_ch` 附近为什么危险 / 我们能测什么。**

---

**假设 1 —— 过渡区厚度 `L_TR ≈ 1 Mm`，直接规定**

- **是什么**：不算过渡区有多厚，直接规定成 100 万米。
- **为什么**：这是 Sokolov 相对前人的**关键改动**。前人规定的是"过渡区**顶部的温度**"，
  他改成规定"过渡区的**厚度**"。这样每条 thread 用同一个数就行。他原话说这是
  "an important distinction from previous works"。
- **危险**：真实的过渡区厚度随磁场强度、加热率变化很大。规定成常数，等于假装两万条 thread 都一样。
- **我们能测**：**现在还不能。** 我们域顶只到 22 kK，跨不了整个过渡区。要等域往上延伸之后
  （第 9 节第 5 步）。**别拿现在的 15.7 km 热边界层厚度去比那个 1 Mm——那是两个不同的量。**

---

**假设 2 —— `{N_i T}` 是常数（压强穿过过渡区不变）**

- **是什么**：把压强当常数从积分里拉出来。
- **为什么**：过渡区的温度梯度尺度远小于重力标高，重力来不及压出压强差。
- **危险**：越靠近 `T_ch` 温度梯度越缓，这个论证越弱；而且**动态时**（比如蒸发）压强会变。
- **我们能测**：直接量 `{N_i T}` 在 6~22 kK 内的变化，以及它在动态过程中偏离多少。

---

**假设 3 —— 稳态（不含时）**

- **是什么**：方程里没有时间导数。传导下来多少，就辐射掉多少。
- **为什么**：过渡区很薄、热传导很快，弛豫时间短，所以"永远处在瞬时平衡"。
- **危险**：耀斑、蒸发、CME 的时候完全不成立——那时候整层都在动。
- **我们能测**：随时间量它偏离传导-辐射平衡多少。**跑蒸发就是在打破这一条。**

---

**假设 4 —— 过渡区底部热流 = 0**

- **是什么**：热量全部从上面（日冕）来，底下既不漏出去也不进来。
- **为什么**：Sokolov 用的词是 **postulate**（假定）——这是用来把 Eq. 20 左边在 `T_ch` 处的
  那一项直接丢掉的。原话："we postulate that the TR is heated solely by the heat transfer from
  the corona and the lower boundary of the transition region is where the heat flux from the corona
  turns to zero."
- **危险**：如果色球正在被抽干或被灌满，底部当然有热流。
- **我们能测**：**直接量底部的传导热流。这是八条里最直接、最好测的一条。**

---

**假设 5 —— 辐射用光学薄的 CHIANTI 表**

- **是什么**：`Λ_R(T)` 按"光子发出来就直接跑掉"算。
- **为什么**：日冕确实是光学薄的，CHIANTI 表就是为日冕做的。
- **危险**：**在 1~2 万 K 那是光学厚的色球**——光子会被别的氢原子吸收、再发射，出不去。
  **Carlsson & Leenaarts (2012) 这整篇论文存在的理由就是这个。**
- **我们能测**：沿本次跑自己的 (ρ, T) 轨迹，把 CL2012 和光学薄 CHIANTI 直接比，
  **找出两者交叉的温度**。

---

**假设 6 —— 氢全电离（`N_e = N_i` = 总氢原子数）**

- **是什么**：Eq. 20 那一步把 `N_e N_i` 写成 `(N_i)²` 时要求的。
- **为什么**：为了能把 `N_i T` 拉出积分号。
- **危险**：C7 模型说 `T_ch` 处电离度 **x = 0.75（10⁴ K）到 0.97（2×10⁴ K）**，
  所以全电离是 **3~25% 的误差**。
  **注意：不是数量级的错误**——早先的草稿写成 "x ~ 10⁻²，所以完全错"，那是把中色球
  （1000~1400 km）的数字用错了地方，已更正。
- **我们能测**：柱子直接给出真实的 `x`。**更有意思的是**：`T_ch` 那两倍的自由度让这个误差
  变化约 **8 倍**——所以它是第 9 节第 0 步的第二条曲线。

---

**假设 7 —— 能量账里没有电离能**

- **是什么**：Eq. 19–22 从头到尾只有传导和辐射，**没有 `χ_H n_H x` 这一项**。
- **为什么**：在"全电离"的假设下电离度不变，就没有电离能的进出，这一项自然消失。
  **它不是被忽略的，是被假设 6 顺手抹掉的。**
- **危险**：穿过我们这一层，电离度从 **0.24 涨到 1.00**（实测），每电离一个氢原子要 13.6 eV。
  这笔能量必须有人付，付账的就是从上面传下来的热。
- **我们能测**：传导输入里有百分之几进了电离库，而不是被辐射掉或被气流带走。
  **只要 `x` 在变，这个数就不可能是零——所以这一条几乎保证有非零结果。**

---

**假设 8 —— `T_e = T_i`（电子和离子一个温度）**

- **是什么**：三维模型本来是**三温**的（电子 + 平行/垂直离子温度），但在低日冕退回单温。
- **为什么**：他自陈是**为了省计算量**——原话 "to improve the computational efficiency"。
- **危险**：Eq. 19–22 里每一项其实都是**电子**量：`κ₀T^{5/2}` 是电子热导、`Λ_R` 是 `T_e` 的函数、
  `N_e N_i` 是电子数×离子数。**三个电子量被一个符号 `T` 混在一起了。**
- **我们能测**：**已经测了**——域内电子-离子均衡时间 `τ_eq = 0.09~3.9 ms`，比 661 个格子里
  每一个竞争时标都短。**所以在当前域里单温是很好的近似，不用改。** 但域往上延伸到 4×10⁵ K
  之后 `τ_eq` 涨到约 3.7 s，那时就得改（第 9 节第 5 步）。

---

**总结这八条：在日冕里它们都很好。** 问题全部集中在积分的**下限** `T_ch` 附近——
也就是色球顶——**而那里正是我们柱子所在的地方。**

### 2.7 关键：`T_ch` 到底落在哪里

这是整件事最重要的一个几何事实。

`T_ch` 是个**自由参数**，Sokolov 只说"大约 1 到 2 × 10⁴ K"。用 C7 层结把这个温度范围换算成高度：

| `T_ch` 取值 | C7 高度 |
|---|---|
| 1×10⁴ K | **2146.3 km** |
| 2×10⁴ K | **2151.8 km** |

> **`T_ch` 整整两倍的自由度，在高度上只跨 5.5 公里。**
>
> **而这 5.5 公里，完全落在我们柱子的里面**（域顶 2153 km）。

这就是为什么这根柱子是唯一能回答这些问题的仪器：**别人的模型要么在这一层之上（AWSoM、MAS），
要么把这一层当成边界条件（TFLM），只有把这 553 公里真的解出来，才能说出这里发生了什么。**

### 2.8 Sokolov 自己标出了这个口子

他在论文里写了这么一句：

> "There is still a minor uncertainty in the way to distinguish the TR from the top of the
> chromosphere, originating from the fact that **we do not include a consistent chromosphere model.**"

**"我们没有一个自洽的色球模型。"** ——这是他自己写的。

他接着说这个不确定性"可以忽略，因为色球的标高很小"（"the barometric scale in the chromosphere
is small"）。

**这句"可以忽略"是对的，但它只覆盖了一件事。** 它说的是"两边接缝的**位置**在哪"——
这是个**静态的、几何的**问题：色球标高小，所以接缝往上往下挪一点，压强变化不大。**这个论证成立。**

**它没有覆盖的（每一条都是动态的或者热力学的）：**

| 没覆盖的 | 为什么它不覆盖 |
|---|---|
| 穿过接缝的**质量流** | 那是动态的，"位置"的论证够不着 |
| 传下来的能量有多少变成**电离能** | 他的方程里根本没有这一项（假设 7） |
| 假设 2（压强恒定）在动态下还成不成立 | 蒸发时压强会变 |
| 假设 4（底部热流为零）在色球被抽干/灌满时 | 那时底部当然有热流 |
| 假设 5 的光学薄辐射表在 1~2 万 K 能不能用 | **不能**——那是光学厚的色球 |

> **这就是我们要补的口子。**
>
> 而且它是**被主人自己标出来的**——做他邀请你做的事，不是在挑他的错。
> 论文引言里应该**直接引这句话**：它同时是动机、是授权、也是礼貌。

## 3. 那个"人为的水库"—— 比上面那句话更硬的证据

Sokolov 那句是"我们没做"。但 AWSoM 实际上**做了别的事**，而那件事更值得写在论文开头。

### 3.1 数字

AWSoM 在色球内边界钉死了这么一组值（**van der Holst et al. 2014，原始论文逐字核对过**）：

```
N_e = N_i = 2×10¹⁷ m⁻³        T_e = T_i = T_i∥ = 50,000 K
```

原文：

> "**We overestimate the density for this temperature by an order of magnitude** with the value of
> Ne = Ni = 2×10¹⁷ m⁻³ at the inner boundary."
>
> "**This overestimate prevents chromospheric evaporation** and extends the upper chromosphere to
> reach the correct lower density, but does not significantly change the global solution as shown in
> Lionello et al. (2009)."

### 3.2 "高估一个数量级"是精确校准的

Sokolov 自己 2013 年的论文里，色球顶的取值是 `N_ch ≈ 2×10¹⁶ m⁻³`。

**AWSoM 用的 `2×10¹⁷` 正好比它高 10 倍。同一组人，两篇自己的论文，差整十倍。**

（Sachdeva et al. 2021 用到 `5×10¹⁸ m⁻³`，那是 **250 倍**。）

### 3.3 为什么要高估

因为**模型底下没有色球**。如果密度按真实值给，过渡区就会"漏干"——底部供不上物质，
过渡区往上跑掉。

> 类比：**一个没有水源的水池。** 你要模拟水池表面的蒸发，但你没有河也没有雨。
> 于是你在池底放一个"无限大的假水箱"，保证水永远抽不干。

**那个假水箱，就是我们的柱子要替换掉的东西。**

### 3.4 有意思的是：他们自己也说不清这水库是干嘛的

同一个数字，这组人在不同论文里给了**四种不同的理由**（全部逐字核对过）：

| 说法 | 论文 |
|---|---|
| **阻止**蒸发 | van der Holst 2014、Sachdeva 2019/2021 等 |
| **允许**蒸发去自洽地填满日冕 | Jin et al. 2017a/b，一直用到 Panesar 2026 |
| **补充**被蒸发带走的物质 | Sachdeva 2023 |
| 阻止**过度的**蒸发 | Shi 2022 |
| 完全不提蒸发，改用纯辐射论证 | van der Holst 2026（多离子模型） |

> **这不是我们在挑刺。这是"数值占位符"的典型特征——如果它是一个物理边界条件，
> 大家会知道它是干什么的。**
>
> 所以论文里要写的不是"AWSoM 压制了蒸发"（那样说不准确，也容易得罪人），而是：
> **"一个比该组自己色球顶值高十倍的固定密度，被每篇论文沿用，而他们对它用途的描述
> 在'阻止蒸发'和'允许蒸发'之间摇摆。"**

### 3.5 代价是被报告出来的

这个近似的代价，在他们自己的论文里被独立报告了三次：

- AWSoM 的密度在 1.025–1.055 R☉ 相对观测反演（DEMT）**偏高**
- 活动区谱合成里**低温通道偏亮**（因为低温等离子体密度太大）
- AWSoM-R 恒星版论文报告 `T < 10^6.2 K` 处**密度高估**

**这三条是同一个症状。**

## 4. "这没关系"的依据 —— 读完之后

每篇 AWSoM 论文都引 **Lionello, Linker & Mikić (2009)** 来说"密度高估不影响全局解"。
**没有一篇重推过。** 我们把这篇拿到手读了（`../supporting-papers/LionelloLinkerMikic2009.pdf`）。

它确实说了那句话。**但是：**

### 4.1 证据是一个"2 倍"测试

原文：

> "It is not crucial to estimate the required chromospheric density accurately; **it is best to
> overestimate it.** An overestimation will simply produce a slightly thicker plateau region,
> without affecting the overall solution. Figure 1 demonstrates this property..."

**而 Figure 1 测的是 `2×10¹²` 对 `4×10¹²` cm⁻³ —— 2 倍。**

引用链条是：

```
一维回路里一个 2 倍测试
   → "最好高估它"
      → 全球模型里 10 倍的边界条件
         → 250 倍的边界条件
```

**没有人在更大的倍数上重测过。**

### 4.2 论文自己划了 500,000 K 的有效性下限

Lionello 的另一个近似是**人为把过渡区加宽**（把热导率在 500,000 K 以下设成常数，
过渡区宽了约 **400 倍**）。他说这没关系——但紧接着写：

> "the emission of the loop in EUV is not significantly modified **for coronal temperatures
> (above ∼500,000 K)**. **More accurate calculations at lower temperatures can be achieved by
> lowering the temperature at which the modification occurs, with the consequence of a requirement
> for higher resolution.**"

**翻译：500,000 K 以上没问题；以下要更准，就得把那个门槛压低，代价是分辨率。**

现在把三件事放在一起：

| | |
|---|---|
| Lionello 声称有效的范围 | **T > 500,000 K** |
| AWSoM 内边界所在的温度 | **50,000 K**（低一个数量级） |
| 密度高估被报告的温度 | **T < 10^6.2 K** |

> **这个封闭的唯一权威，明确地把自己的有效性划在了误差出现的区域**之外**。**
>
> 这条比"我们怀疑这个公式在这里不对"好写得多——**是他们自己说的，我们只是引用。**

### 4.3 而且机制画在他自己的图里

Lionello 的 Figure 3(a) 里，加宽后的（红）曲线在过渡区**压在**原始（蓝）曲线上方——
近似让过渡区**既更宽、在同一高度上又更密**。

**所以 AWSoM 报告的低高度密度超出不是意外副作用，它就是这个近似被演示出来的行为，
画在那篇被引来证明"这个近似无害"的论文里。**

## 5. 我们的柱子是什么

### 5.1 它是什么

一根**沿磁力线的一维柱子**，跨 **1600 km 到 2153 km**（553 km），温度 **6631 K 到 22,000 K**。
正好就是 Sokolov 说"接缝位置不确定"的那一层。

- **单流体**：一个密度、一个速度、一个温度（三个守恒量 `ρ, ρu, E`——**和 BATS-R-US 的状态向量
  形状一致**）
- **Saha 平衡电离**：电离度 `x` 由温度密度算出来，**电离能算进总能量里**
- **物理热传导**，SWMF 的精确 Riemann 求解器，双精度
- 下边界 1600 km **不是光球**，是"模型截断面"——底下不属于这个模型

### 5.2 它很便宜

实测：**0.199 core-秒 / 物理秒**（单核比实时快 5 倍）。一次 4000 秒的标准跑，12 线程约 **11 分钟**。

**这一点很关键**：host 叫 AWSoM-**R**ealtime，Sokolov 的动机就是过渡区太贵。
所以"我们选了保留主要电离能量学的最便宜的封闭"是**设计要求**，不是妥协。

### 5.3 它已经被验证过一次，而且结果很好

C7 模型（Avrett & Loeser 2008，一个**细致的非 LTE 半经验模型**）在 1617 km 给的电离度是
**x = 0.240**。

我们的柱子用**纯氢 LTE Saha** 在自己的 (ρ, T) 上算出来是 **x = 0.273**。

> **差 14%。**
>
> 这是在这个封闭最可疑的高度上、对着一个细致 NLTE 模型的验证。也是"为什么平衡电离在这里够用"
> 最强的一句回答。

## 6. 我们要交付什么 —— 分两批，别混起来

**不是代码，不是耦合。** 但也不是一次交完——**有两批，时间差好几个月，而且性质完全不同。**

*（这一节 2026-09-06 重写。早先的版本直接说"我们交付一个函数"，跳过了第一批，
和第 7 节的四个数字接不上。**那是个真实的不一致，已修正。**）*

### 6.0 先说清一件容易搞混的事：柱子不是函数

交付物是一个函数，**但我们的柱子不是函数**——它是一个含时 PDE 求解器。这两件事的接口不一样：

| | 是什么 | 谁定 |
|---|---|---|
| **`T_TR`** | 域顶的温度 | **我们规定**（外部导热壁的温度） |
| **`p_top`** | 域顶的压强 | **我们规定**（外部压强资料 `p_ref`） |
| `T_ch` | 色球顶在哪 | **从解里读**——后处理时挑一条等温线，说"这里算合并点" |
| `L_TR` | 过渡区多厚 | **从解里读**——`T_ch` 到 `T_TR` 有多远 |

**只有前两个是输入。后两个是读数。** 记住这个，后面的循环问题就不难懂了。

### 6.1 第一批（Tier 1）：审计数字 —— 现在的域就能做

**这一批是论文的主体，而且这一批里 `p_top` 是输入，不是输出。**

因为我们的域顶（22 kK，2153 km）**就在 `T_ch` 上**（1–2 万 K，2146–2152 km），
而 Eq. 21 是从 `T_ch` 一路积到 `T_TR ≈ 4×10⁵ K`——**在我们头顶上还有 1 Mm。**

> **当前的柱子完全在积分区间的下面。它不计算 `{N_i k_B T}`，它接收 `{N_i k_B T}`。**

它做的是另一件事：**把 thread 交下来的那两个数当作已知，去测下面发生了什么。**

交付的是四个百分数（第 7 节）：假设 4、5、6、7 各偏多少，加上假设 8 的时标测量。
**这是一篇完整的论文，不依赖域延伸。**

### 6.2 第二批（Tier 2）：那个函数 —— 要等域往上延伸

```
{N_i k_B T}(T_TR, L_TR, T_ch)
```

一个修正版的、包含**部分电离**和**电离能**的关系式。Sokolov 那边**替换一个函数就行，
不需要采纳我们的代码**。

**只有把域顶提到 `T_TR ≈ 4×10⁵ K`（+1.0 Mm，第 9 节第 5 步）之后，柱子才真正跨过那段积分，
压强才从输入变成输出。**

### 6.3 那不是自相矛盾吗？—— 循环怎么解开

很自然会问：**我们在域顶规定压强，又说要输出域顶的压强，这不是把答案当输入吗？**

在当前域上，这个质疑成立——所以 6.1 明确写了"我们不产出它"。

延伸之后，解开循环的是这个事实：**Eq. 21 是四个量之间的一个方程。**

```
(p, T_TR, L_TR, T_ch)   四个量，一个关系
⇒ 必须指定三个，第四个才定下来
```

**指定哪三个是你的选择**（Sokolov 自己也说了，他选择规定厚度而不是顶部温度，
是"an important distinction from previous works"）：

```
Sokolov 选:  规定 (T_TR, L_TR, T_ch)  →  解出 p
我们只能选:  规定 (T_TR, p_top)       →  读出 L_TR    ［对每个挑定的 T_ch］
```

**同一条关系，同一张四维曲面，只是从不同的面进去。** 具体做法：

```
在 (T_TR, p_top) 上扫一个二维网格
   → 每次跑出一条剖面
      → 每条剖面上挑若干个 T_ch，读出对应的 L_TR 和压强
         → 得到一堆 (T_TR, p, L_TR, T_ch) 的点
            → 反演成 Sokolov 的参数化：p(T_TR, L_TR, T_ch)
```

> **所以压强那一维必须扫。只扫 `T_TR` 得到的是一条一维切片，反演不出来。**
>
> 这不是补丁，这就是数值标定一条隐式关系的标准做法。

**顺带一个副产品**：现在 `p_ref` 的数值来自初始条件，从来没被变过。而它同时也是第一批
（审计）里所有数字的前提——"偏离 40%"这句话后面必须能接"在什么条件下"。
**所以压强扫描对两批都是必需的，理由还不一样。**（详见 plan §5.4）

### 6.4 顺带澄清：`p_ref` 不是"IC 的残留"

它是**Sokolov 的封闭交下来的那个量本身**。我们的域顶就是 thread 的底面，thread 往下交两样东西，
正好就是柱子消费的两样：

| AWSoM-R 交下来 | 我们这边 |
|---|---|
| 一个压强值（假设 2：`{N_i T}` 穿过 TR 不变） | `kOuterPRef` |
| 一个导热关系（Eq. 22 的 Robin 条件，**不是**单独给温度） | 22 kK 导热壁 + 自由浮动的 hydro ghost 温度 |
| 两个都是常数（假设 3：稳态） | 两个都固定 |

所以"把压强固定住"**不是偷懒，是忠实复现被审计的那个封闭**——那个封闭本身就是静态的。
反过来，把压强放松才是不一致的：那等于把被审计的对象换成了 host 里根本不存在的东西。

真正站得住的批评不是"固定不物理"，而是"**这个值只来自 IC，而且从没被扫过**"——那是第 6.3 节
末尾那条，值得做。

### 6.5 这个套路在这个领域是标准做法

不是我们发明的。**Carlsson & Leenaarts (2012)** 就是这么干的：把昂贵的辐射转移计算跑一遍，
拟合成便宜的公式；然后 Bifrost 这样的大模型直接用那个拟合，**不必自己去做昂贵计算**。

> **"把昂贵的一维物理蒸馏成给大模型用的便宜配方"——这已经是这个圈子公认的方法论。**
>
> 我们做的是同一件事，往上一层：**从辐射损失换成电离能量学，从 Bifrost 换成 AWSoM-R。**

## 7. 四个数字（论文活在这里）

这四个都不是新的基础物理。**它们全都是会改变别人做法的新数字。**

对应关系（接上第 6 节）：**②③ 是第一批（Tier 1）的核心，④ 是方法论文那条线，
① 有两个版本——一个现在就能做，一个要等域延伸。**

### ① 压强偏多少

公式算出来的 `{N_i k_B T}` 是 P，真算一遍是 P'。报告 `(P'−P)/P`。**一个百分数。**

> 类比：天气模型在地表用经验公式估蒸发量。你不是在发明蒸发的物理，
> 你是在测**那个公式偏了多少**。偏 30%，上面所有云量预报都跟着偏。

**这条有两个版本，别混：**

- **便宜版（Tier 0，零模拟，一个下午）**：拿 Eq. 21 算出来的 `{N_i k_B T}`，
  和**我们柱子顶部实际的压强**比。柱子顶是 `p_top ≈ 0.0103 Pa`（全电离，所以
  `{N_i k_B T} = p_top/2 ≈ 0.0051 Pa`）。
  **这不循环**——柱子的顶部压强不是 Eq. 21 算的，是 C7 大气静力学积分来的。
  所以这个比较问的是：**那个解析封闭，能不能重现一个细致半经验大气在合并高度的压强？**
- **完整版（Tier 2，几个月）**：域延伸之后，按 6.3 的办法扫 `(T_TR, p_top)` 再反演。

### ①.5 顺带说明：为什么第一批里 ① 只有便宜版

因为当前域顶在 22 kK，就在 `T_ch` 上，而 Eq. 21 从 `T_ch` 积到 `T_TR ≈ 4×10⁵ K`——
**我们整个在积分区间下面，跨不了那段积分**（第 6.1 节）。

**②③④ 不受这个限制**，因为它们测的都是"给定交接，下面发生了什么"，不需要跨过积分区间。

### ② 有多少热"存"进了电离里

从日冕传下来的热，去处只有三个：辐射掉、被气流带走、**用来把氢原子的电子扯下来**。

**Sokolov 的公式里只有第一个。整套方程里根本没有电离能。**

但穿过这一层，电离度从 **0.24 涨到 1.00**（实测）。每电离一个氢原子要 13.6 eV，
这笔钱必须有人付。

> 类比：**烧水的潜热。** 加热水温度往上走；到 100°C 之后继续加热，温度不动了——
> 能量全去变蒸汽了。**电离就是氢的"潜热"。Sokolov 的公式假装没有潜热这回事。**

**这一条风险最低**：只要 `x` 在变，这一项就不可能是零。

### ③ 那个没人定过的旋钮

公式要你告诉它色球到哪算完：`T_ch`。Sokolov 说"大概 1 到 2 × 10⁴ K"——**两倍的范围，
没人钉死过。** 而 `T_ch` 是公式里两个积分的下限。

> 类比：**说明书上写"这个旋钮大概拧到 1 和 2 之间"。** 你去测：拧到 1 和拧到 2，结果差多少？
> 如果差很多，那这个公式的输出就是靠一个没人定过的旋钮决定的——**这本身就是发现。**

**这一条不用跑任何模拟**，就是做积分，一个下午。所以它排第一——先告诉你后面值不值得投入。

### ④ 声速该用哪个

声速取决于气体被挤压时有多"硬"，就是绝热指数 γ。

- 普通单原子气体：**γ = 5/3 ≈ 1.67**
- 部分电离气体：挤压时一部分能量跑去电离/复合了，气体变"软"，这一层里 **γ ≈ 1.09**

声速 ∝ √γ，两者差约 **25%**。

哪个对，取决于电离反应跟不跟得上波：跟得上用 1.09（平衡），跟不上用 5/3（冻结）。
**两个都是合法的极限**，我们的代码在 Riemann 求解里用冻结的 5/3。

交付一张 **Damköhler 数**的图（`Da = 电离弛豫时间 / 流体变化时间`），告诉别人**哪里该用哪个**。

| 不做 | 为什么 |
|---|---|
| **不做真正的 SWMF 耦合** | 组件封装、MPI、构建集成、回归套件——那是软件工程，不是科学，也不是说服审稿人的东西。所有假设都能**离线**检验 |
| **不跑三维日冕模型** | 一次都不跑。但**一维柱子的顶端最终要伸到过渡区温度**（见第 9 节）——这两件事不一样 |
| **不做 Alfvén 波** | host 自己就把整个色球波物理压缩成**一个标定常数** `{S_A/B}`，加在色球顶部。我们的整个域在他的公式里就是个黑箱。**这是继承，不是缺陷** |
| **不宣称改进了 Poynting flux 标定** | 那是波能注入问题。我们没有波、没有感应方程、没有磁场演化 |
| **不宣称取代 TRAC** | 只说给 TRAC 类方法提供一个**可标定的参考解** |
| **不宣称覆盖日冕的总物质供应** | Type II 针状体可能才是主力，它由双极扩散和多维重联驱动，我们结构上做不到。**只声称"热驱动的物质加载通道"** |
| **不从磁图驱动跑** | Bin 2 四个数字都是**局部热力学**问题；磁流管几何改变数字大小，不改变假设成不成立。而且这是方法论项目滑向软件项目的典型路径 |

## 9. 路线图

### 第 0 步：不跑模拟（几天）

纯求积。**在跑任何模拟之前做这个**，它决定后面值不值得。三件事，同一个 `T_ch` 扫描：

1. **辐射通道**：Eq. 21 配 CHIANTI 表，看 `{N_i k_B T}` 随 `T_ch` 变多少
2. **电离通道**：全电离假设的误差随 `T_ch` 变多少（C7 表已经编译在代码里，不需要 CHIANTI）
3. **直接对照**：Eq. 21 的输出 vs 我们柱子顶部的压强（`{N_i k_B T} ≈ 0.0051 Pa`）——
   **这是整个计划里最便宜的一次实质接触**，而且能给第 3.5 步的压强扫描定个中心值

### 第 1 步：加辐射损失（几周）

**必须同时加背景加热项。** 只加辐射汇不加源，色球会在几百到几千秒内冷塌——
而那正是我们所有长跑的时间尺度。

做法用最简单的：`Q_h(s) = Λ_R(ρ₀, T₀)`，锁在初始态上，让 t=0 能量平衡。这是这个领域的标准做法
（HYDRAD、Johnston 的 TRAC 系列都这么干），一句话就能辩护：**"我们不声称解释色球加热；
我们要求初始态平衡，好让测到的偏离来自动力学而不是不平衡的初始条件。"**

### 第 2 步：一次 4000 秒基线跑（11 分钟）

**这一次跑就产出八行审计表里的六行**：假设 6、7、4、5、2、8，外加 Damköhler 图。
**是整个计划里性价比最高的单次模拟。**

### 第 3 步：frozen-x 对照跑

`x` 锁在初始值。给第 2 步的每个数字配误差棒。

### 第 3.5 步：压强扫描（几小时）

**加一个 `ISO_OUTER_PREF` 开关**（几行代码：让外部压强资料可以从环境变量设，不设就还是现在
由初始条件决定的行为），**然后扫 3–5 个点。**

**两个独立的理由，都成立：**

1. **第一批需要它**——第 2 步测出来的"偏离 X%"，后面必须能接"在什么条件下"。
   `p_ref` 从来没被变过，所以现在那句话是不完整的。
2. **第二批需要它**——按 6.3 节，配方要反演就必须有压强这一维。只有一个值，
   得到的是一条一维切片，反演不出来。

**不要用"把压强放松"来代替。** 放松之后压强的**绝对水平**没有东西按住，
顶压会一路涨（`~ln t`，永远不收敛），柱子为了减重从底部排水，
所有绝对速度小 ~20 倍——**而压强正是我们要交付的那个量。参照系自己在动，就什么都测不了了。**

### 第 4 步：蒸发扫描

改变顶部热流 F，测峰值蒸发速度，检验 `v_e ∝ F^{1/3}`（Longcope 2014）。
**这是跨代码对照，而且不需要跑别人的代码。** 5~8 次跑，两小时内。

### 第 5 步：域往上延伸（几个月）

**规格写温度，不写高度**，因为公式积到的是 `T_TR`。目标 **`T_TR ≈ 4×10⁵ K`**
（由 `L_TR = 1 Mm` 自洽定出），在 C7 层结下约合 **+1.0 Mm**。

分两步：先 **+50 km 到 10⁵ K**（去风险：测辐射表交叉点、撞一次导热刚度、逼出网格问题），
再 **+1.0 Mm**。**双温度在这一步和延伸一起做**，不能分开排。

**不要伸到 100 万 K**——那要 +17 Mm，而且那是日冕不是过渡区，对这个封闭零贡献。

## 10. 常见问题

### Q：没有 Alfvén 波，会不会出问题？

**在能量输运上不会——那是继承的。** AWSoM-R 把波的边界条件
`{S_A/B} = 1.1×10⁶ W m⁻² T⁻¹` 加在**色球顶部**。也就是说我们整个域在 host 自己的公式里
就是一个黑箱，只负责交出那一个标定常数。波在里面怎么反射、怎么耗散，AWSoM-R 也没算。

**但有一处真实暴露，而且就在第 1 步：** 波流量约是色球总辐射损失的 25~55%，
文献还把沉积高度指到 1900–2150 km（正是我们域的上半部）。所以**加辐射汇必须同时加加热源**。
这已经写进路线图。

**动量那一侧（波压、ponderomotive 力）**结构上做不到——那是 spicule 和 FIP 效应的通道。
Sokolov 自己也把波压梯度从方程里丢掉了。**划界，不辩护。**

### Q：Igor 为什么要分离电子和离子温度？

四个理由，前两个能写进论文：

1. **接口要求。** AWSoM 是**三温**模型（各向同性 `T_e` + 平行/垂直离子温度）。交一个 `T` 过去，
   host 就得任意拆——等于把刚解决的不确定性还回去。
2. **那个公式本来就是电子方程，却写成了单温。** `κ₀T^{5/2}` 是电子热导、`Λ_R` 是 `T_e` 的函数、
   `N_e N_i` 是电子×离子密度——**三个电子量被一个符号混同了**，而 host 自陈理由是"省计算量"。
3. **部分电离下源和汇作用在不同粒子上**：传导、辐射、电子碰撞电离都是电子通道；
   离子-中性摩擦是离子通道。一个温度把它们平均掉了。
4. SWMF 历史原因：单温 CME 激波会有非物理的热前驱。

**但我们实测：域内 `τ_eq = 0.09–3.9 ms`，比 661 格里每一个竞争时标都短。**
所以在当前域里分离两温改不动任何东西——**推到第 5 步，和向上延伸一起做**。

这个回答比"还没做"强得多：**"我算过了，在当前域里是 10⁻⁵ 量级的效应，而且我知道
它从哪个高度开始重要。"**

### Q：Igor 为什么让我跑蒸发？

**因为 host 现在是用一个假水箱把蒸发按住的**（第 3 节）。他们对那个数字的四种解释，
每一种都是**关于蒸发的**。让你跑蒸发，就是让你产出替换那个占位符的量。

另外三个理由：蒸发是**唯一**能测穿过接缝的质量流的方式（静态测试够不着）；
它**同时**打破假设 3（稳态）和 4（底部热流为零）；它是这个领域的**标准 benchmark**，
说的是审稿人已经在说的语言。

### Q：没有新物理，能发论文吗？

**这个领域里几乎没人发现新物理。** 大家在做的是：建一个太贵的模型 → 把贵的部分换成便宜近似
→ **总得有人去查那个近似行不行**。第三步是一整个体裁，而且**引用最多的论文都在那里**：

| 论文 | 做了什么 | 有新物理吗 |
|---|---|---|
| Lionello 2009 | "热导率在 500 kK 以下设常数，过渡区宽 400 倍，日冕察觉不到" | 没有。**但它是 AWSoM/MAS 整条线的地基** |
| Bradshaw & Klimchuk 2013 | 拿现成模型跑不同分辨率，报告"网格太粗日冕密度就低一倍" | **连新模型都没有。** 88 引用 |
| Carlsson & Leenaarts 2012 | 把昂贵的 NLTE 计算拟合成便宜公式 | 没有，就是个拟合。**每个三维色球模拟都在用** |

**贡献的单位不是"发现"，是一个能让别人改变做法的数字。**

检验方法一句话：**读完你的论文，有人会做出不一样的事吗？**

- "这个公式在 15,000 K 以下偏 40%" → AWSoM 组要改 `T_ch`、加修正、或缩小声称的有效范围。✅
- "我们的模型更自洽" → 没人做任何不一样的事。❌

所以**摘要第二句必须是**：*We find that [某个量] departs by [数字] under [条件].*
如果不是，就先去把那个数字拿回来。

### Q：可以从磁图出发跑一维色球吗？

**技术上可以，而且比想象的便宜**——release 求解器已经支持任意规定的磁流管
（`grid.B_i`/`grid.B_iph`，面积因子已经在通量差分里），仓库里也已经有 `pfss_field_line` 场景。
链路是：磁图 → PFSS → 描场线 → `B(s)` → `A(s) ∝ 1/B(s)` → 喂给柱子。**这正是 TFLM 在做的事。**

**但这篇论文不要做**（理由见第 8 节）。

**更锐利的版本留给第 5 步之后**：真正重要的参数不是磁图，是**足点的 B**，因为 AWSoM 是
**逐 thread** 施加修正的。跑一个覆盖真实 B 范围的小系综（宁静区 ~5–10 G、网络 ~50 G、
活动区 ~500 G），回答"修正量依赖 B 吗"。如果依赖，交付物就从三个自变量变成四个：

```
{N_i k_B T}(T_TR, L_TR, T_ch)   →   {N_i k_B T}(T_TR, L_TR, T_ch, B)
```

**磁图在这里的作用不是输入，是告诉你 B 该扫哪个范围——那是一张直方图，不是一次模拟。**

最近的应用**原封不动地在用**；AWSoM_R 1.0 是 NASA CCMC 的社区模型。

**但注意一个信号**：van der Holst et al. 2026 的多离子模型里，那个 `2×10¹⁷ m⁻³` 还在，
但**关于蒸发的说法不见了**，改成了纯辐射的论证。**数字没动，理由在漂移。**
