Detailed Description

Counters for the (rho,E) -> T ENERGY inversion, i.e.

the safeguarded Newton/bisection solve of e_int(rho,T) = e_int that the decode and projection stages run per cell. Deliberately separate from PressureInversionProfile, which counts the (rho,p) -> T face inversion of the MUSCL reconstruction.

std::uint64_t chromosphere::EosInversionProfile::bracket_evaluations = 0
