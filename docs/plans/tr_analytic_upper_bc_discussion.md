# 用解析 TR 给色球上边界：可行性讨论（白话版）

**Status: PLAN.** 2026-11-09 的讨论记录。没有改代码，也没有跑新模拟。依据是 AWSoM-R 论文（Sokolov et al. 2021, ApJ 908, 172，`docs/supporting-papers/`）和本地 SWMF 里的 TR 代码。相关的前一篇讨论：[outer_pressure_bc_floating_discussion.md](outer_pressure_bc_floating_discussion.md)。

---

## 先回答三个问题

| 问题 | 简短回答 |
|---|---|
| 能让边界自洽吗？ | **能自洽一半。** 温度可以和压强对上，但压强本身还是得有人从外面给。 |
| 数值上够解方程吗？ | **只靠这条链不够。** 边界要回答两个问题，这条链只回答了其中一个。 |
| 和 AWSoM-R 一致吗？ | **方向正好相反。** AWSoM-R 固定 TR 底温度，让压强去变；你的想法是让压强决定温度。AWSoM-R 这么选有很好的理由（见第 4 节）。 |

## 1. 画面

```
   日冕（AWSoM-R 负责）
   ───────────────  TR 顶：约几十万到一百万 K
   过渡区 TR（很薄，用解析公式代替）
   ───────────────  TR 底 = 我们的上边界（2153 km，约 2 万 K）
   色球（我们的模拟柱子）
   ───────────────  下边界（1600 km）
```

**现在的做法：** 在上边界直接写死两个数，温度 T_ch = 22000 K、压强 P ≈ 0.01 Pa。

**问题：** 这两个数是各自随手选的。真实大气里，TR 底的温度和压强之间有关系：日冕送下来多少热、TR 在这个压强下辐射掉多少，这笔账要对得上。随手选的一对数，上面未必真有一个 TR 能维持它。

**你的想法：** 在边界上面接一个解析的 TR，让它根据压强算出 T_ch。链条是：

> 压强高 → TR 密度高 → 辐射更多 → 能传到底部的热更少 → 底部更冷

这个因果方向是对的，而且是自我调节的：压强偏高时底部变冷，蒸发变弱，往上送的气体变少，压强就回落。

---

## 2. 能自洽吗：能自洽一半

**能做到的：** T_ch 不再随手定，而是跟压强、跟上面送下来的热保持一致。

**做不到的：** 压强本身是多少，TR 定不了。

打个比方：TR 像一条很短的过道，热从上面经过它往下走，气体从下面经过它往上走，但它本身不储存东西。压强的高低取决于日冕里积了多少气体、日冕本身热不热，这些都发生在 TR 之上。

所以压强只能从以下三处之一来：

1. **外面给**（AWSoM-R，或者像现在一样写死）。这样 T_ch 就跟着压强走，比现在进了一步。
2. **从色球内部推出来**。这就是上一篇讨论过的“压强浮动”方案。以前跑过一次，蒸发几乎消失（小了约 19 倍），气体反而从底部漏掉。那次是在旧的数值方法下跑的，还没在新方法下重跑。
3. **再加一个很简单的日冕模型**，记录蒸发上去的气体越积越多、压强随之上升。这是单柱里唯一能让压强本身也自洽的办法，但这已经是在加模型，不只是改边界了。

换句话说，“外面给的数”不会消失，只会搬家：从“TR 底的温度和压强”搬到“TR 顶的日冕温度和热量”。搬家本身是好事，因为后者正是 AWSoM-R 真正算出来的量。

## 3. 数值上够不够：边界要回答两个问题

在我们的上边界，方程要求外面回答**两个**问题（这是上一篇讨论里数出来的）：

1. **力学问题：** 上面在“推”还是在“让”？也就是说，气体往上走时会不会被顶回来。现在靠写死的压强回答。
2. **热的问题：** 上面送下来多少热？现在靠写死的温度回答。

你的链条（压强 → 温度）回答的是第 2 个。如果压强也取自色球内部，第 1 个问题就没人回答了。程序照样能跑，但压强没有“锚”，会慢慢漂走。上面说的蒸发消失、底部漏气就是这个现象。

所以还需要一条关于第 1 个问题的外部信息。有两种给法：

- 直接给日冕压强；
- 让 TR 根据蒸发速度给出压强：蒸发越快，TR 能维持的压强越低。这样压强不是写死的，但大体上由 TR 顶的日冕条件决定，不会漂走。第 6 节详细解释这条链。

## 4. 和 AWSoM-R 一致吗

AWSoM-R 的做法是：**TR 底温度固定**（SWMF 代码里是 1 万 K），**压强由 TR 公式算出来**。你的想法正好反过来：压强是输入，温度是输出。

为什么 AWSoM-R 敢随手固定底温度？因为它几乎不影响结果。我用 SWMF 的辐射表算了一下：TR 辐射掉的能量绝大部分发生在十万 K 以上，2 万 K 以下那一段不到总量的 0.4 %。所以底温度取 1 万 K 还是 3 万 K，TR 的整笔账几乎不变。

反过来就麻烦了。既然底温度对账目几乎没影响，那么要从账目**反推**底温度时，压强里 1 % 的误差就能让 T_ch 在 1 万 K 和 5 万 K 之间乱跳。此外，2 万 K 附近的辐射本来就不是这个简单公式能描述的（那里的氢只部分电离，光也逃不出去），所以让这个公式来决定 T_ch，等于在它最不可靠的地方用它。

（这个估算没有算蒸发带走的能量。算上以后底部会敏感一些，但上面的结论应该不变。）

和 AWSoM-R 一致的地方也有：

- **压强应该和色球连续。** AWSoM-R 论文自己写了：TR 应该和色球“压强不跳变”地接上，只是他们没有色球模型，做不到。这一点上，你的想法正好补上他们的缺口。
- **蒸发。** SWMF 现在的代码里，TR 公式已经包含了“蒸发带走的能量”，并且留了一个参数：色球顶的上流速度。但 AWSoM-R 一直把这个速度设成 0，因为它不知道色球在干什么。**我们的柱子正好能提供这个速度。**

## 5. 建议

**最省事、也最符合 AWSoM-R 的版本：**

- T_ch 照旧固定（22000 K）。
- 压强不再写死，而是由 SWMF 那张 TR 表根据我们柱子顶部的上流速度算出来。
- 这样两个问题都有了物理上的回答：热的问题由固定温度回答，力学问题由 TR 算出的压强回答。外面只需要给日冕温度和 TR 厚度，这正是 AWSoM-R 本来就有的量。
- 逻辑链条见第 6 节。

**如果一定想让温度跟着压强变：** 让 TR 交给色球的是“剩下多少热流进来”，而不是“温度是多少”，温度交给色球自己去算。这样可以避开第 4 节说的乱跳问题。

**动手之前先做的便宜检查（都不用跑模拟）：**

1. 确认 T_ch 指的是什么：是“TR 底部本身的温度”，还是“2153 km 这个固定高度上的温度”？后者会随 TR 上下移动而变，物理意义不同。
2. 用 SWMF 的表检查现在的 (22000 K, 0.01 Pa)：要维持它，上面需要多热的日冕、多厚的 TR？如果答案合理，说明现在的“不自洽”其实不严重。
3. 在新数值方法下把“压强浮动”方案重跑一次，看蒸发是否仍然消失。

## 6. 推荐版本的逻辑链条

### 6.1 一句话

每一步，我们把柱子顶部的**蒸发速度**交给 TR 表，TR 表还给我们一个**压强**，我们把这个压强放到上边界上。温度照旧是 22000 K。

### 6.2 一步一步

```
 外面给定（不随时间变）：TR 顶的日冕温度、TR 的厚度
                     │
   ┌─────────────────▼──────────────────┐
   │ ① 柱子顶部：气体正以某个速度往上走（蒸发）     │
   │ ② 这股气体进入 TR，要被加热到日冕温度，         │
   │    还要把氢电离掉，这笔能量从日冕传下来的热里扣  │
   │ ③ 热被分走一部分，能用来辐射的就少了            │
   │ ④ 辐射少，说明 TR 里的气体没那么密            │
   │    （辐射随密度平方增长）                     │
   │ ⑤ TR 的厚度和顶温度都定了，密度低就是压强低     │
   │ ⑥ 这个压强就是 TR 底的压强，放到我们的上边界    │
   └─────────────────┬──────────────────┘
                     ▼
   ⑦ 柱子在新的边界压强下继续演化，顶部速度随之改变 → 回到 ①
```

几点说明：

- **外面给的是什么。** 现在写死的是“TR 底的压强”。换成这个版本以后，写死的是“TR 顶的日冕温度”和“TR 的厚度”。如果和 AWSoM-R 耦合，前者由 AWSoM-R 每一步提供，后者 AWSoM-R 本来也是人为给定的。
- **蒸发为零时，和现在完全一样。** 这时 TR 只给出一个固定压强，相当于现在的写死 P，只是这个 P 不再随手选，而是由日冕温度和 TR 厚度算出来。
- **蒸发不为零时，才出现新东西：** 压强会随蒸发速度自动调整。

### 6.3 边界压强是什么的函数

边界压强 = 函数（TR 顶的日冕温度，蒸发速度）÷ TR 厚度。

- **温度指 TR 顶的日冕温度，不是边界温度 T_ch。** T_ch 固定为 22000 K，不进入这个函数。日冕温度由外部给定：单柱时写死一个值，和 AWSoM-R 耦合时由它每一步提供。
- **速度是我们柱子顶部的蒸发速度**，由柱子自己算，随时间变化。
- **TR 厚度是外部给定的常数**（AWSoM-R 里同样是人为给定的）。

压强对两个变量的敏感程度差别很大：

- **对日冕温度很敏感。** 从 30 万 K 到 100 万 K，压强从约 0.0014 Pa 升到约 0.04 Pa，大约随温度的三次方增长。所以压强的大小基本由日冕温度决定。
- **对速度很不敏感。** 每 10 m/s 只变 3–5 %，相当于在上面那个值附近做小修正（见 6.5）。

一个细节：SWMF 的表用的是 TR 底部 1 万 K 处的速度，而真正要传过去的是质量通量。把质量通量换算成那里的速度要用到那里的密度，也就是要用到压强本身。所以压强其实也出现在等式右边，需要迭代一两次才能定下来。由于压强对速度很不敏感，这个迭代收敛得很快。

### 6.4 蒸发是怎样降低压强的

可以这样理解：**蒸发的气体分走了 TR 里的热，于是能辐射的热变少，TR 的密度和压强就要低一些。**

具体分三步：

1. **日冕传下来的热几乎不变。** 复算的表里，蒸发速度从 −40 m/s 变到 +100 m/s，TR 顶传下来的热通量只变化几个百分点。
2. **变的是这份热怎么分。** 在 TR 里，这份热有两个去处：一是辐射掉，二是把从色球上来的冷气体加热到日冕温度、再把其中的氢电离。蒸发越快，第二项花得越多，留给辐射的就越少。
3. **辐射少，就意味着密度低。** 辐射随密度的平方增长。在日冕温度和 TR 厚度都给定的情况下，TR 只有密度低一些才能“恰好”辐射掉剩下的那部分热。等压的 TR 里密度低，压强就低。

需要注意的是，这不是一个“先发生什么、后发生什么”的时间顺序，而是一个定常的能量收支约束：在给定的蒸发速度下，TR 只有一个密度能让这笔账收平。

**模型里没有、方向却相反的效应：** 蒸发上去的气体会在日冕里积累，时间长了会**提高**日冕和 TR 的压强。这才是真实冕环里蒸发的主要作用。但这个效应发生在 TR 之上（日冕的质量收支），解析 TR 模型里没有它。所以在这个版本里，蒸发只表现为“TR 的热被分走、压强略降”这一短期效应；“日冕被填满、压强升高”的长期效应要靠日冕模型或者和 AWSoM-R 耦合才能得到（见第 2 节和 6.8）。

### 6.5 这个调整有多大

数字来自对 SWMF TR 表的离线复算：按 `ModTransitionRegion.f90` 的公式重新实现，CHIANTI 8.0 辐射表，Z = 1。没有运行 SWMF 本身。

先看蒸发为零时 TR 给出的压强（TR 厚度取 1.5 Mm，SWMF 实际用 1.4–2.8 Mm）：

| TR 顶温度 | TR 底压强 |
|---|---:|
| 10 万 K | 约 0.0001 Pa |
| 30 万 K | 约 0.0014 Pa |
| 100 万 K | 约 0.04 Pa |

现在 release 用的 0.0103 Pa 落在 30 万 K 和 100 万 K 之间，是合理的量级。

再看蒸发速度对压强的影响（相对于蒸发为零时的压强）：

| TR 底的上流速度 | 30 万 K | 100 万 K |
|---:|---:|---:|
| −40 m/s（往下落） | +12 % | +23 % |
| −10 m/s | +3 % | +5 % |
| 0 | 0 | 0 |
| +10 m/s | −3 % | −5 % |
| +30 m/s | −9 % | −13 % |
| +100 m/s | −27 % | −37 % |

（这里的速度是表里的定义：TR 底部、1 万 K 处色球气体的速度。我们柱子顶部的速度在 22000 K 处测得，要按质量通量换算过去，不能直接拿来用。）

release 现在的蒸发速度大约是 10 m/s 的量级，所以**压强只会自动调低几个百分点**。也就是说：

- 在 release 这种平缓的蒸发下，这个版本和“写死压强”差别不大。它最主要的变化是外面给的量换了：从“TR 底压强”换成了“日冕温度 + TR 厚度”，后者有物理来源。
- 蒸发或凝结越强，差别越大。

### 6.6 这个回路会不会失控

一圈下来是这样的：

- 柱子这边：边界压强低一点，顶部气体就稀一点，同样的质量通量需要更快的速度。
- TR 这边：速度快一点，压强又低一点。

两边是同向的，所以回路会**放大**一个扰动，而不是抵消它。但放大得很弱。按上表，速度变化 10 %（约 1 m/s）只让压强变化 0.3–0.5 %；压强变 0.4 % 左右，柱子顶部的速度大约也只变 0.4 %，远小于最初的 10 %。所以一圈下来扰动只剩原来的几个百分点，所以会收敛到一个稍微偏离的平衡点，不会失控。如果蒸发速度到了几十 m/s 以上，就需要实际跑一下确认。

### 6.7 两个问题各由谁回答

| 边界要回答的问题 | 由什么回答 |
|---|---|
| 力学：上面推不推得动气体 | TR 算出的压强（大体由日冕温度和 TR 厚度决定，随蒸发小幅调整） |
| 热：上面送下来多少热 | 固定温度 22000 K（和现在一样） |

两个问题都有外部回答，所以不会出现“压强浮动”方案里那种压强慢慢漂走的情况。

### 6.8 还需要处理的地方

1. **TR 底的温度对不上。** SWMF 的表从 1 万 K 开始算（这是代码里写死的常数），我们的边界在 22000 K。要么用 22000 K 重新算一张表，要么把 1 万到 2.2 万 K 这一段的账补上。按第 4 节，这一段对辐射几乎没影响，但对“加热、电离进入的气体”这笔账有影响（氢的电离能就在这一段花掉）。第 8 节采用前一种做法：从 22 kK 起算，并去掉电离能项，因为在我们的边界处，柱子已经把氢电离完了。
2. **流进色球的热对不上。** 表里假设 TR 底传进来的热刚好够把进入的气体加热、电离。我们柱子顶的热由自己的热传导算，没有被要求和表一致。可以先只做诊断：跑的时候把两者都输出出来比一比。
3. **压强本身仍然主要由外部决定。** 这个版本让压强和蒸发对上了，但压强的大小主要还是由“日冕温度 + TR 厚度”决定。要让压强真正由“日冕积了多少气体”决定，仍然需要第 2 节说的日冕模型，或者和 AWSoM-R 真正耦合。

### 7.2 辐射表长什么样

表文件的前 5 行是说明：标题、一行格式参数、行数 600、CHIANTI 版本 8.0、列名。之后每行两个数：log₁₀T，以及以 10⁻²² erg cm³ s⁻¹ 为单位的 Λ。温度从 10^3.2 K 到 10^8 K。下面摘了几行：

| log₁₀T（表中第 1 列） | T [K] | Λ [10⁻²² erg cm³ s⁻¹]（表中第 2 列） |

### 7.3 三个公式

符号和 AWSoM-R 论文一致，完整的符号表见 8.3。假设与 SWMF 的表相同：TR 很薄，所以总压强 $P$ 在 TR 里处处相同；状态定常；没有流动；氢完全电离。只用到三个量：温度 $T$、往下传的热流 $q$（取正值）、压强 $P$。

**(1) 热往下传：**

$$
q = \kappa_0\,T^{5/2}\,\frac{dT}{ds}
$$

**(2) 一边传一边辐射掉：** 热每往下走一段 $ds$，就被这一段的辐射吃掉一部分：

$$
\frac{dq}{ds} = N_eN_i\Lambda_R(T), \qquad N_e = N_i = \frac{P}{2k_BT}
$$

把 (1) 和 (2) 合起来消掉 $s$，再从 TR 底（温度 $T_{\rm ch}$，热流 $q_{\rm ch}$）积分到 TR 顶（温度 $T_{\rm TR}$，热流 $q_{\rm TR}$），得到

$$
q_{\rm TR}^2 = q_{\rm ch}^2 + \frac{\kappa_0\,P^2}{2k_B^2}\int_{T_{\rm ch}}^{T_{\rm TR}}\sqrt{T}\,\Lambda_R(T)\,dT \tag{A}
$$

式中的积分就是对 7.2 那张表做数值积分。

**(3) TR 的厚度：** 由 (1)，$ds = \kappa_0T^{5/2}\,dT/q$，所以

$$
L_{\rm TR} = \int_{T_{\rm ch}}^{T_{\rm TR}}\frac{\kappa_0\,T^{5/2}}{q(T)}\,dT \tag{B}
$$

其中 $q(T)$ 由 (A) 的上限换成 $T$ 得到。

**计算步骤：**

1. 给定 $T_{\rm ch}$、$q_{\rm ch}$、$T_{\rm TR}$，先猜一个 $P$，用 (A) 算出沿途的 $q(T)$，再用 (B) 算出 $L_{\rm TR}$。
2. 调整 $P$，直到 $L_{\rm TR}$ = 1.5 Mm。这时的 $P$ 就是 TR 的压强。
3. 定标：取 release 的 $T_{\rm ch}$ = 22 kK、$q_{\rm ch}$ = 0.527 W/m²，调整 $T_{\rm TR}$，使第 2 步得到 $P$ = 0.0103 Pa。结果是 $T_{\rm TR}$ = 477 kK，$q_{\rm TR}$ = 162.6 W/m²。
4. 各图的画法：
   - **左图：** $q_{\rm TR}$、$q_{\rm TR} - q_{\rm ch}$、$q_{\rm ch}$。没有流动时，进来的减去从底部出去的，就是 TR 辐射掉的。
   - **中图：** 只把 $q_{\rm ch}$ 从 0 改到 5.27 W/m²，每个值都重做第 2 步。
   - **右图：** 只把 $T_{\rm ch}$ 从 10 kK 改到 50 kK，每个值都重做第 2 步。

### 7.4 从公式直接看出为什么两条线是平的

- **中图：** 在 (A) 里，$q_{\rm ch}^2$ = 0.28，而 $q_{\rm TR}^2$ = 26 400，$q_{\rm ch}$ 只占右边的十万分之一。所以 $q_{\rm ch}$ 变 10 倍，$P$ 也几乎不用变。
- **右图：** $T_{\rm ch}$ 只改变 (A) 中积分的下限。按 7.2 的表，$\Lambda_R$ 在 1–5 万 K 一段比峰值小得多，这一段只占整个积分的约 1 %。所以 $T_{\rm ch}$ 从 1 万 K 变到 5 万 K，$P$ 只变约 1 %。
- **反过来读为什么不行：** 要从 $P$ 求 $q_{\rm ch}$，就得用 (A) 计算 $q_{\rm ch}^2 = q_{\rm TR}^2 -$（含 $P^2$ 的大数），也就是两个约 26 400 的数相减，剩下 0.28。$P$ 只要偏高 0.0005 %，差就变成负数，TR 无解。

### 7.5 和 SWMF 自己的表的关系

SWMF 的 `check_tr_table` 在无流动时固定 $T_{\rm ch}$ = 1 万 K、$q_{\rm ch}$ = 0，所以它的表只是 $T_{\rm TR}$ 的函数（那一列是压强乘以 $L_{\rm TR}$）。这里只是把 $T_{\rm ch}$ 和 $q_{\rm ch}$ 两个量放开。另外要注意：SWMF 表里的压强是**电子压强**，即总压强的一半。§6.3 和 §6.5 中的压强数值（30 万 K 时 0.0014 Pa，100 万 K 时 0.04 Pa）是电子压强，换成总压强分别约为 0.003 Pa 和 0.08 Pa。本节和示意图用的都是总压强。

本节没有考虑流动（蒸发带走的焓）、重力，以及 1 万 K 以下的电离。这些和 SWMF 无流动时的那张表一致。

## 8. 推荐边界条件的推导（带流动）

本节把第 6 节的推荐版本写成能直接实现的公式。和第 7 节一样只做了离线计算，没有改代码。推导从原始的一维流体方程出发，逐条应用假设化简。符号尽量沿用 AWSoM-R 论文（Sokolov et al. 2021），见 8.3。与 SWMF 的表相比有三处不同：积分从我们的边界温度 22 kK 开始，而不是 1 万 K；电离能项在化简中严格消去；流动用质量通量表示。理由见 8.5。

### 8.1 要定的只有一个数

现在的上边界在两个 ghost cell 里放：温度 22 kK；速度取顶格速度（有马赫数上限）；压强取固定值 `kOuterPRef`（第二个 ghost 由静力平衡往上推一格）；密度由 EOS 从压强和温度算出（`scenarios/model_column.cpp`，outer face 一段）。推荐版本只把 `kOuterPRef` 换成 TR 算出的压强 $P_{\rm TR}$，其余不变。所以只需推导 $P_{\rm TR}$。

### 8.2 各方程适用的区域

```
  高度                        区域                      在这里用的方程           怎么解
  ─────────────────────────────────────────────────────────────────────────────────────────
  2153 km + L_TR 以上         日冕                      不解（单柱）/ AWSoM-R     只提供 T_TR
  ─── s = L_TR，T = T_TR ────────────────────────────────────────────────────────────────────
  2153 km ~ 2153 km + L_TR    TR 区域 Ω_TR               (8.1)–(8.3) → (8.7)–(8.9)  定常，沿 T 积分
  ─── s = 0，T = T_ch ── 接口 = 柱子上边界（顶面）；ghost cell 在它上方 ────────────────────────
  1600 km ~ 2153 km           柱子区域 Ω_col             release 方程（含时）      数值求解，不变
  ─── 1600 km ── 下边界 ──────────────────────────────────────────────────────────────────────
```

- **柱子区域 Ω_col（1600–2153 km）。** 用 release 求解器解，方程和数值方法都不变。它和 (8.1)–(8.3) 是同一组方程，但 release 在这里没有加热项和辐射项。本节的推导不涉及这个区域。
- **TR 区域 Ω_TR（$0 \le s \le L_{\rm TR}$，对应 $T_{\rm ch} \le T \le T_{\rm TR}$）。** $s$ 从接口起算，向上为正（AWSoM-R 论文的 $s$ 从太阳表面起算，只差一个常数）。原始方程 (8.1)–(8.3)、所有化简步骤和最终的 (8.7)–(8.9) **都只在这个区域内成立**。这里没有网格，只做一维积分。
- **接口（$s = 0$，即 2153 km 的顶面）。** 两个区域在这里交换四个量：
  - 柱子交给 TR：质量通量 $\rho u$、传导热流 $q_{\rm ch}$。它们作为 (8.7) 的参数和初值。
  - TR 交给柱子：压强 $P_{\rm TR}$。它放进第一个 ghost。
  - 温度 $T_{\rm ch}$ 双方共用，是固定值。

  四个量都连续，所以接口两侧的焓通量、电离能通量和传导热流也都连续。
- **TR 顶（$s = L_{\rm TR}$）。** 只用到一个条件：$T = T_{\rm TR}$。TR 顶以上的日冕不在本模型里。

### 8.4 原始方程（在 Ω_TR 内）

这是沿磁力线的一维、含时、单流体方程组。磁流管截面积正比于 $1/B$，所以散度写成 $B\,\partial(\cdot/B)/\partial s$，和论文式 (13)–(15) 相同。$E$ 里包含电离能，这一点和柱子的 release 方程相同。

**质量：**

$$
\frac{\partial\rho}{\partial t} + B\frac{\partial}{\partial s}\left(\frac{\rho u}{B}\right) = 0 \tag{8.1}
$$

**动量：**

$$
\frac{\partial(\rho u)}{\partial t} + B\frac{\partial}{\partial s}\left(\frac{\rho u^2}{B}\right) = -\frac{\partial P}{\partial s} - \rho g \tag{8.2}
$$

**能量：**

$$
\frac{\partial E}{\partial t} + B\frac{\partial}{\partial s}\left[\frac{(E + P)\,u - q}{B}\right] = -\rho u\,g + Q_{\rm heat} - N_eN_i\Lambda_R(T) \tag{8.3}
$$

(8.3) 左边方括号里是向上的总能量通量：$(E+P)u$ 是对流携带的能量（动能、焓、电离能），$-q$ 是传导（$q$ 向下为正，所以带负号）。右边依次是重力做功、加热和光学薄辐射 $Q_{\rm rad}$。

**把 $E$ 展开。** 这里还没有用到任何假设，所以按部分电离的纯氢来写。用电离度 $x$ 表示各个数密度和压强：

$$
N_e = N_i = \frac{x\rho}{m_p},\qquad N_{\rm HI} = \frac{(1 - x)\rho}{m_p},\qquad P = (N_{\rm HI} + N_i + N_e)\,k_BT = (1 + x)\frac{\rho k_BT}{m_p}
$$

单位体积总能量是动能、热能、电离能三项之和：

$$
E = \underbrace{\frac{\rho u^2}{2}}_{\text{动能}} + \underbrace{\frac{P}{\gamma - 1}}_{\text{热能}} + \underbrace{N_i\chi_{\rm H}}_{\text{电离能}}
= \frac{\rho u^2}{2} + \frac{1 + x}{\gamma - 1}\,\frac{\rho k_BT}{m_p} + \frac{x\rho\,\chi_{\rm H}}{m_p}
$$

对应的向上能量通量是

$$
(E + P)\,u - q = \rho u\left[\frac{u^2}{2} + \frac{\gamma}{\gamma - 1}\,\frac{(1 + x)k_BT}{m_p} + \frac{x\,\chi_{\rm H}}{m_p}\right] - \kappa\frac{\partial T}{\partial s}
$$

方括号里依次是单位质量的动能、焓、电离能。这里的 $\kappa$ 是一般的热传导系数（柱子里是 $\kappa_e + \kappa_n$），完全电离时才变成 $\kappa_0T^{5/2}$（8.5 第 3 步）。代入 (8.3)，能量方程完整写出来是

$$
\frac{\partial}{\partial t}\left[\frac{\rho u^2}{2} + \frac{1 + x}{\gamma - 1}\,\frac{\rho k_BT}{m_p} + \frac{x\rho\,\chi_{\rm H}}{m_p}\right]
+ B\frac{\partial}{\partial s}\left\{\frac{\rho u}{B}\left[\frac{u^2}{2} + \frac{\gamma}{\gamma - 1}\,\frac{(1 + x)k_BT}{m_p} + \frac{x\,\chi_{\rm H}}{m_p}\right] - \frac{\kappa}{B}\frac{\partial T}{\partial s}\right\}
= -\rho u\,g + Q_{\rm heat} - \left(\frac{x\rho}{m_p}\right)^2\Lambda_R(T)
$$

8.5 的各步化简就是对这个式子做的。

### 8.5 逐条应用假设

下面每一步都只在 Ω_TR 内做，顺序是：先写出假设，再代入具体数值估算要忽略的项，最后才把它去掉。每一步用三个标记：**假设**、**估算**、**结论**。

**参考值。** 下面的估算都用这一组数：

| 量 | 值 | 来源 |
|---|---|---|
| $T_{\rm ch}$ | 22 kK | release 现在的上边界温度 |
| $P_{\rm TR}$ | 0.0103 Pa | release 现在的上边界压强 |
| $L_{\rm TR}$ | 1.5 Mm | 假设 |
| $T_{\rm TR}$ | 477 kK | 选定：使 $\rho u = 0$ 时 TR 公式正好给出 0.0103 Pa（见 8.8） |
| $\rho u$ | 2.68×10⁻¹⁰ kg m⁻² s⁻¹ | release 柱顶，$t$ = 4000 s |
| $q_{\rm ch}$ | 0.53 W/m² | release 柱顶，$t$ = 4000 s |
| $u_{\rm ch} = \rho u/\rho_{\rm ch}$ | 9.5 m/s | TR 底的速度，$\rho_{\rm ch} = m_pP_{\rm TR}/(2k_BT_{\rm ch})$ |
| $u_{\rm TR}$ | 205 m/s | TR 顶的速度，同一公式取 $T_{\rm TR}$（且 $P \approx P_{\rm TR}$） |
| $g$ | 274 m/s² | $GM_\odot/R_\odot^2$ |

标 † 的量（$q_{\rm TR}$、辐射功率、沿 $s$ 的积分）需要 TR 的温度分布，取自最终的解 (8.7)–(8.9)。它们只用来事后检验被忽略的项确实很小，不参与推导本身。

**第 1 步：定常，$\partial/\partial t = 0$。**

- **假设：** TR 回到平衡所需的时间，比它的输入（柱子顶部的 $\rho u$、$q_{\rm ch}$）变化的时间短得多。
- **估算：** TR 的弛豫时间取“TR 里存的热能 ÷ 每秒流进来的热”。TR 里压强处处相同，单位体积热能是 $\frac32P$，所以
  $$
  \tau_{\rm TR} = \frac{\tfrac32P_{\rm TR}L_{\rm TR}}{q_{\rm TR}^{\dagger}} = \frac{1.5\times0.0103\times1.5\times10^{6}}{163} \approx 140\ \text{s}
  $$
  它和论文给的 TR 弛豫时间 $2L_{\rm TR}/[(\gamma-1)U_{\rm heat}(T_{\rm TR})]$ 在代数上相同。输入变化的时间取 $\rho u$ 变化掉自身所需的时间。22 kK 的 release 在 $t$ = 4000 s 时 $\rho u$ 每 500 s 下降 3.1 %（`docs/studies/boundaries/twall_mass_flux_relaxation_timescales.md`），即 $d(\rho u)/dt = -1.65\times10^{-14}$ kg m⁻² s⁻²，所以
  $$
  \tau_{\rm drive} = \frac{\rho u}{|d(\rho u)/dt|} = \frac{2.68\times10^{-10}}{1.65\times10^{-14}} \approx 1.6\times10^{4}\ \text{s}
  $$
- **结论：** $\tau_{\rm TR}/\tau_{\rm drive} \approx 0.01$，含时项约为其他项的 1 %，去掉。这个比值只在柱子调整完之后成立：22 kK 时柱子顶部要到约 1600 s 才调整完（e 折时间约 530 s），在那之前比值约 0.26，定常只是粗略近似。

**第 2 步：$B$ 不变，即截面不变。**

- **假设：** 和 release 的 $B = 1$ 一致。这时 $B\,\partial(\cdot/B)/\partial s = d(\cdot)/ds$。不需要估算。

经过这两步，(8.1)–(8.3) 变为

$$
\frac{d(\rho u)}{ds} = 0 \tag{8.4}
$$

$$
\frac{d}{ds}\big(P + \rho u^2\big) = -\rho g \tag{8.5}
$$

$$
\frac{d}{ds}\left[\rho u\,\frac{E + P}{\rho} - q\right] = -\rho u\,g + Q_{\rm heat} - N_eN_i\Lambda_R(T) \tag{8.6}
$$

由 (8.4)，**$\rho u$ 在整个 Ω_TR 里是常数**，等于接口处柱子交来的值（论文式 (13) 的 $\{\rho u/B\}$ = 常数，在 $B$ 不变时就是这一条）。

**第 3 步：完全电离，$N_{\rm HI} = 0$，$N_e = N_i$。**

- **假设：** 氢完全电离，$x = 1$。
- **估算：** 柱子用纯氢 Saha 平衡；在 22 kK、0.01 Pa，Saha 给出的中性氢比例约 3×10⁻⁹，温度更高处更小。
- **结论：** 于是

$$
P = 2N_ik_BT,\qquad \rho = m_pN_i,\qquad \frac{E + P}{\rho} = \frac{u^2}{2} + \frac{2\gamma}{\gamma - 1}\frac{k_BT}{m_p} + \frac{\chi_{\rm H}}{m_p},\qquad \kappa = \kappa_0T^{5/2}
$$

其中 $\frac{2\gamma}{\gamma-1}\frac{k_BT}{m_p}$ 是单位质量的焓，$\gamma = 5/3$ 时等于 $5k_BT/m_p$；论文式 (18) 的焓通量写的是同一个量。最后一式取柱子自己的系数：柱子的 $\kappa_e$（`src/single_fluid/integrator.cpp` 中的 `mixture_kappa_e`）在 $N_{\rm HI} \to 0$ 时正好退化成 $\kappa_0T^{5/2}$，$\kappa_0 = 9.2048\times10^{-12}$ W m⁻¹ K⁻⁷ᐟ²。

代入 (8.6)，方括号里多出一项 $\rho u\,\chi_{\rm H}/m_p$。由于 $\rho u$ 是常数，这一项也是常数，它的导数为零。**所以电离能在 Ω_TR 里严格消去，不是近似。** SWMF 的表需要电离能项，是因为它的 TR 底在 1 万 K，气体进入 TR 时还是中性的，电离发生在它的积分区间内。我们的接口在 22 kK，按柱子的 Saha 闭合，氢在柱子里已经电离完，电离能已经计入柱子的 $E$。

这个假设沿用了柱子的 LTE 闭合。真实的 TR 不处于 LTE，22 kK 附近的氢未必完全电离；第 4 节已经指出，这个温度段本来就不是这个简单模型能可靠描述的。

**第 4 步：能量方程，逐项估算后去掉动能和重力做功。**

- **假设：** 动能项和重力做功项比能量收支里的大项小得多。
- **估算：** 先把 (8.6) 在 Ω_TR 上积分，**所有项都保留**（$x = 1$，$\gamma = 5/3$，$\Delta T = T_{\rm TR} - T_{\rm ch}$）：
  $$
  q_{\rm TR} - q_{\rm ch} = \rho u\,\frac{5k_B\Delta T}{m_p} + \rho u\,\Delta\!\left(\frac{u^2}{2}\right) + \rho u\,g\,L_{\rm TR} - \int_0^{L_{\rm TR}}Q_{\rm heat}\,ds + \int_0^{L_{\rm TR}}N_eN_i\Lambda_R\,ds
  $$
  每一项代入参考值：

  | 项 | 算式 | W/m² |
  |---|---|---:|
  | 进来减出去的热 | $q_{\rm TR}^{\dagger} - q_{\rm ch} = 163 - 0.5$ | 162 |
  | 加热上流气体 | $2.68\times10^{-10}\times5k_B\times(477 - 22)\ \text{kK}/m_p$ | 5.0 |
  | 动能 | $2.68\times10^{-10}\times(205^2 - 9.5^2)/2$ | 5.6×10⁻⁶ |
  | 重力做功 | $2.68\times10^{-10}\times274\times1.5\times10^{6}$ | 0.11 |
  | TR 内加热 | 见第 6 步 | — |
  | 辐射† | 余项 | 157 |

  小项和大项之比，先写算式再代数：
  $$
  \frac{\text{动能}}{\text{加热上流}} = \frac{m_p\,\Delta(u^2/2)}{5k_B\Delta T} = \frac{(205^2 - 9.5^2)/2}{1.88\times10^{10}} = 1.1\times10^{-6},\qquad
  \frac{\text{动能}}{\text{进来的热}} = \frac{\rho u\,\Delta(u^2/2)}{q_{\rm TR} - q_{\rm ch}} = \frac{5.6\times10^{-6}}{162} = 3.5\times10^{-8}
  $$
  $$
  \frac{\text{重力做功}}{\text{加热上流}} = \frac{m_p\,g\,L_{\rm TR}}{5k_B\Delta T} = \frac{1.67\times10^{-27}\times274\times1.5\times10^{6}}{5\times1.38\times10^{-23}\times4.55\times10^{5}} = 0.022,\qquad
  \frac{\text{重力做功}}{\text{进来的热}} = \frac{0.11}{162} = 6.8\times10^{-4}
  $$
- **结论：** 两项都去掉。它们最多是加热上流那一项的 2 %，不到整个热量收支的 10⁻³。

**第 5 步：动量方程，逐项估算后得到 $P = P_{\rm TR}$。**

- **假设：** 动压和重力引起的压强变化都可以忽略，TR 里压强处处相同。
- **估算：** 把 (8.5) 在 Ω_TR 上积分：
  $$
  \Delta\big(P + \rho u^2\big) = -\int_0^{L_{\rm TR}}\rho g\,ds
  $$
  动压与压强之比（取 $P \approx P_{\rm TR}$）：
  $$
  \frac{\rho u^2}{P}:\quad \text{TR 底 } \frac{2.8\times10^{-11}\times9.5^2}{0.0103} = 2.5\times10^{-7},\qquad \text{TR 顶 } \frac{1.3\times10^{-12}\times205^2}{0.0103} = 5\times10^{-6}
  $$
  去掉动压后 $d\ln P/ds = -1/H$，压强标高 $H = 2k_BT/(m_pg)$：$H$(22 kK) = 1.3 Mm，$H$(477 kK) = 29 Mm。TR 的大部分长度在高温段，沿 TR 的温度分布† 积分：
  $$
  \Delta\ln P = \int_0^{L_{\rm TR}}\frac{ds}{H} \approx 0.086
  $$
  即 TR 顶的压强比底部低约 8 %。
- **结论：** 动压去掉（论文式 (14) 也去掉了这一项）；重力引起的压降也去掉，于是 $P = P_{\rm TR}$ 处处成立。重力这一项是所有忽略项里最大的。论文式 (20) 前同样假设 $\{N_iT\}$ 在 TR 里不变，理由是 TR 里温度变化的尺度远小于重力的压强标高。

**第 6 步：TR 内没有加热，$Q_{\rm heat} = 0$。**

- **假设：** 这是模型假设，和论文式 (19) 相同：加热沉积在日冕，TR 里只有传导、焓通量和辐射三项之间的平衡。这里没有检验它。

**化简结果（在 Ω_TR 内）：**

$$
\rho u = \text{常数},\qquad P = P_{\rm TR},\qquad
\frac{d}{ds}\left(\rho u\,\frac{2\gamma}{\gamma - 1}\frac{k_BT}{m_p} - q\right) = -N_eN_i\Lambda_R(T),\qquad N_e = N_i = \frac{P_{\rm TR}}{2k_BT},\qquad q = \kappa_0T^{5/2}\frac{dT}{ds}
$$

$\rho u = 0$ 时，这就是论文的式 (19)。积分一次就是 TR 的能量收支：进来的热 = 出去的热 + 加热上流 + 辐射，即 163 = 0.5 + 5.0 + 157 W/m²。

**第 7 步：把自变量从 $s$ 换成 $T$。** 只要 $q > 0$，$T$ 就在 Ω_TR 内严格随 $s$ 增加，$s \in [0, L_{\rm TR}]$ 与 $T \in [T_{\rm ch}, T_{\rm TR}]$ 一一对应，可以换元。由 $q$ 的定义，$dT/ds = q/(\kappa_0T^{5/2})$，所以 $d/ds = [q/(\kappa_0T^{5/2})]\,d/dT$。代入能量方程，两边乘以 $\kappa_0T^{5/2}$：

$$
q\left(\frac{2\gamma}{\gamma - 1}\frac{k_B\rho u}{m_p} - \frac{dq}{dT}\right) = -\kappa_0T^{5/2}\,\frac{P_{\rm TR}^2}{4k_B^2T^2}\,\Lambda_R(T)
$$

整理，并利用 $2q\,dq/dT = d(q^2)/dT$，得到（定义域 $T_{\rm ch} \le T \le T_{\rm TR}$，初值取在接口处）：

$$
\frac{d(q^2)}{dT} = \frac{4\gamma}{\gamma - 1}\,\frac{k_B\rho u}{m_p}\,q + \frac{\kappa_0\,P_{\rm TR}^2}{2k_B^2}\,\sqrt{T}\,\Lambda_R(T), \qquad q(T_{\rm ch}) = q_{\rm ch} \tag{8.7}
$$

$\gamma = 5/3$ 时第一项的系数是 $10\,k_B\rho u/m_p$。右边两项说明，热流往上越来越大有两个原因：要补上下面辐射掉的能量（第二项），以及把上流的气体从 $T$ 加热到更高温度（第一项）。$\rho u = 0$ 时 (8.7) 可以直接积分，退化为第 7 节的式 (A)，也就是论文的式 (20)。

**厚度条件。** 由 $ds = \kappa_0T^{5/2}\,dT/q$，在 Ω_TR 上积分：

$$
L_{\rm TR} = \int_{T_{\rm ch}}^{T_{\rm TR}}\frac{\kappa_0\,T^{5/2}}{q(T)}\,dT \tag{8.8}
$$

### 8.6 最终表达式

**$P_{\rm TR}$ 是下面这个方程的根**：

$$
\int_{T_{\rm ch}}^{T_{\rm TR}}\frac{\kappa_0\,T^{5/2}}{q(T;\,P_{\rm TR},\rho u,q_{\rm ch})}\,dT = L_{\rm TR} \tag{8.9}
$$

其中 $q(T;\,P_{\rm TR},\rho u,q_{\rm ch})$ 是 (8.7) 在 $[T_{\rm ch}, T_{\rm TR}]$ 上的解。(8.9) 是在 Ω_TR 上的积分，但它的结果 $P_{\rm TR}$ 只用在接口处。求出 $P_{\rm TR}$ 后，边界这样设：

- 第一个 ghost：压强 $P_{\rm TR}$（取代 `kOuterPRef`），温度 $T_{\rm ch}$，密度由 EOS 从 $(P_{\rm TR}, T_{\rm ch})$ 求出（完全电离时就是 $\rho_{\rm ch} = m_pP_{\rm TR}/(2k_BT_{\rm ch})$），速度照旧取顶格速度；
- 第二个 ghost：照旧，由静力平衡往上推一格。

第一个 ghost 的中心在顶面上方半个格（约 0.14 km），那里和接口处的静力压强差约 10⁻⁴，所以直接把 $P_{\rm TR}$ 放在那里，和现在放 `kOuterPRef` 的方式一样。

**解一定存在且唯一（在 $q$ 保持为正时）。** $P_{\rm TR}$ 越大，(8.7) 右边越大，$q(T)$ 处处越大，(8.9) 左边就越小。所以左边随 $P_{\rm TR}$ 单调下降，用二分法或 Brent 法都能求根。$\rho u$ 是负值（下落）而且很大时，$q$ 可能在到达 $T_{\rm TR}$ 之前降到零。这时第 7 步的换元失效，表示 TR 维持不了这么强的下落，无解。SWMF 为此把 $u_{\rm ch}$ 限制在 −40 到 100 m/s，我们照做。

**无流动时的显式形式。** $\rho u = 0$、$q_{\rm ch} = 0$ 时，(8.7) 给出

$$
q(T) = \tfrac12 P_{\rm TR}\,U_{\rm heat}(T) = \{N_ik_BT\}_{\rm TR}\,U_{\rm heat}(T)
$$

在 $T = T_{\rm TR}$ 处这就是论文的式 (22)。代入 (8.9) 得

$$
\{N_ik_BT\}_{\rm TR} = \frac{P_{\rm TR}}{2} = \frac{1}{L_{\rm TR}}\int_{T_{\rm ch}}^{T_{\rm TR}}\frac{\kappa_0\,T^{5/2}}{U_{\rm heat}(T)}\,dT \tag{8.10}
$$

这和论文的式 (21) 完全相同，只是我们的 $T_{\rm ch}$ 取 22 kK。用 $T_{\rm TR}$ = 477 kK、$L_{\rm TR}$ = 1.5 Mm 算得 $P_{\rm TR}$ = 0.0103 Pa。这一项是 $P_{\rm TR}$ 的主体，流动只在它上面做百分之几的修正。

**它和 SWMF 的表是同一个结构。** 把 (8.7) 两边除以 $P_{\rm TR}^2$：第一项的系数变成 $\frac{4\gamma}{\gamma-1}\frac{k_B\rho u}{m_pP_{\rm TR}} = \frac{2\gamma}{\gamma-1}\frac{u_{\rm ch}}{T_{\rm ch}}$，其中 $u_{\rm ch} = \rho u/\rho_{\rm ch}$ 是接口处的气体速度。因此 $P_{\rm TR}L_{\rm TR}$ 只依赖 $T_{\rm TR}$ 和 $u_{\rm ch}$（再加上 $q_{\rm ch}/P_{\rm TR}$，影响约 10⁻⁴）。这正是 SWMF 表的 `PavrL` 列：$P_{\rm TR} = G(T_{\rm TR}, u_{\rm ch})/L_{\rm TR}$。区别只在于我们的 $u_{\rm ch}$ 是在 22 kK 处，而且没有电离能项。

### 8.7 最终表达式里每个变量从哪来

| 变量 | 从哪来 | 随时间变吗 |
|---|---|---|
| $T_{\rm ch}$ = 22 000 K | release 现在的 ghost 温度，保持不变。理由见第 4 节和 7.4：$\Lambda_R$ 在 1–5 万 K 一段很小，$T_{\rm ch}$ 几乎不影响 $P_{\rm TR}$ | 不变 |
| $T_{\rm TR}$ | 外部给定。单柱时写死，取 477 kK：这个值让 $\rho u = 0$ 时的 $P_{\rm TR}$ 正好等于现在的 0.0103 Pa，所以新边界在 $t = 0$ 时和 release 完全一样。与 AWSoM-R 耦合时取它的 $T_{\rm TR}$（电子温度） | 单柱不变；耦合时每步更新 |
| $L_{\rm TR}$ | 外部给定的常数，1.5 Mm（AWSoM-R 里由追踪磁力线的步长决定，1.4–2.8 Mm，见第 9 节） | 不变 |
| $\rho u$ | 柱子自己算：取上一步通过顶面的 Godunov 质量通量。求解器已经算出这个量，不用另算。滞后一步的误差可以忽略：时间步约 6 ms，$P_{\rm TR}$ 对 $\rho u$ 又很不敏感 | 每步更新 |
| $q_{\rm ch}$ | 柱子自己算：上一步传导求解器在顶面的热流（已经写进 `.outercond` 诊断文件）。取 0 只让 $P_{\rm TR}$ 变约 10⁻⁴，所以也可以不传 | 每步更新（或取 0） |
| $\kappa_0$ = 9.2048×10⁻¹² W m⁻¹ K⁻⁷ᐟ² | 柱子自己的 Spitzer 系数，见 8.5 第 3 步。用同一个值，TR 和柱子的热传导才一致。SWMF 的值是 9.22×10⁻¹²，相差 0.2 % | 常数 |
| $\Lambda_R(T)$ | SWMF 的 `RadCoolCorona_8.0.dat`（CHIANTI 8.0），表值乘以 10⁻³⁵ 换成 W m³，见 7.2 | 常数 |
| $\gamma$，$k_B$，$m_p$ | 常数 | 常数 |
| $q(T)$ | 中间量，由 (8.7) 积分得到，不是输入 | — |
| $\rho_{\rm ch}$，$u_{\rm ch}$ | 由 $P_{\rm TR}$、$T_{\rm ch}$、$\rho u$ 推出，不是输入 | — |

注意：$P_{\rm TR}$ 几乎正好与 $L_{\rm TR}$ 成反比（见 (8.10)），所以 $L_{\rm TR}$ 和 $T_{\rm TR}$ 一样重要。在 $\rho u = 0$ 时，$(T_{\rm TR}, L_{\rm TR})$ 平面上有一整条曲线都给出同一个 $P_{\rm TR}$。选定 $L_{\rm TR}$ 在效果上等于选定压强的大小。

**怎么算。** 两种办法都行：

- 每步直接对 (8.9) 求根，$\rho u$ 作为已知量代入。这样不需要额外迭代。每次求根要积分 (8.7) 几十次，每次积分在 ln T 上取约 300 点，和 SWMF 的表一样。
- 预先做一张 $G(T_{\rm TR}, u_{\rm ch})$ 表，每步用 $u_{\rm ch} = \rho u/\rho_{\rm ch}(P_{\rm TR})$ 迭代两三次。$\ln P_{\rm TR}$ 对 $\ln u_{\rm ch}$ 的导数只有约 −0.016，每迭代一次误差缩小约 60 倍。

### 8.9 为什么电离能在 TR 里能消去，在色球里不能

8.5 第 3 步说电离能在 Ω_TR 里严格消去。这一节从部分电离的原始公式出发，说明消去的条件是什么，以及为什么这个条件在色球（Ω_col）里不成立。

**原始公式（部分电离的纯氢，$B$ 不变）。** 用电离度 $x$ 表示各个量：

$$
N_e = N_i = \frac{x\rho}{m_p},\qquad N_{\rm HI} = \frac{(1 - x)\rho}{m_p},\qquad P = (1 + x)\frac{\rho k_BT}{m_p}
$$

$$
E = \frac{\rho u^2}{2} + \frac{P}{\gamma - 1} + \frac{x\rho\,\chi_{\rm H}}{m_p}
$$

质量方程和能量方程就是 (8.1)、(8.3) 在 $B$ = 常数时的形式：

$$
\frac{\partial\rho}{\partial t} + \frac{\partial(\rho u)}{\partial s} = 0 \tag{8.11}
$$

$$
\frac{\partial E}{\partial t} + \frac{\partial}{\partial s}\Big[(E + P)\,u - q\Big] = -\rho u\,g + Q_{\rm heat} - N_eN_i\Lambda_R(T) \tag{8.12}
$$

在柱子里，$x$ 由 Saha 方程给出（release 的闭合），随 $T$ 和 $\rho$ 变：

$$
\frac{x^2}{1 - x} = \frac{m_p}{\rho}\left(\frac{2\pi m_ek_BT}{h^2}\right)^{3/2}\exp\!\left(-\frac{\chi_{\rm H}}{k_BT}\right)
$$

其中 $m_e$ 是电子质量，$h$ 是普朗克常数。release 在柱子里不含 $Q_{\rm heat}$ 和辐射项，但下面的论证与这两项无关。

**把电离能项单独拆出来。** $E$ 中的电离能 $x\rho\chi_{\rm H}/m_p$ 对 (8.12) 左边的贡献是

$$
\frac{\chi_{\rm H}}{m_p}\left[\frac{\partial(x\rho)}{\partial t} + \frac{\partial(x\rho u)}{\partial s}\right]
= \frac{\chi_{\rm H}}{m_p}\left[x\left(\frac{\partial\rho}{\partial t} + \frac{\partial(\rho u)}{\partial s}\right) + \rho\left(\frac{\partial x}{\partial t} + u\frac{\partial x}{\partial s}\right)\right]
= \frac{\chi_{\rm H}}{m_p}\,\rho\,\frac{Dx}{Dt} \tag{8.13}
$$

中间一步的第一个圆括号由 (8.11) 为零。$D/Dt = \partial/\partial t + u\,\partial/\partial s$ 是跟着流体元的时间导数。把 (8.13) 移到右边，(8.12) 变为

$$
\frac{\partial E'}{\partial t} + \frac{\partial}{\partial s}\Big[(E' + P)\,u - q\Big] = -\rho u\,g + Q_{\rm heat} - N_eN_i\Lambda_R(T) - \frac{\chi_{\rm H}}{m_p}\,\rho\,\frac{Dx}{Dt},\qquad E' = E - \frac{x\rho\,\chi_{\rm H}}{m_p} \tag{8.14}
$$

$E'$ 只含动能和热能，和论文式 (7) 中的能量（不计磁能）相同。所以电离能等价于右边的一个源项：气体被电离时（$Dx/Dt > 0$）它吸收能量，复合时（$Dx/Dt < 0$）它放出能量。**电离能项为零的条件是：每个流体元在运动中电离度都不变，$Dx/Dt = 0$。**

**部分电离和完全电离的对比：**

| | 部分电离（色球，Ω_col） | 完全电离（TR，Ω_TR，$x \equiv 1$） |
|---|---|---|
| $N_e = N_i$ | $x\rho/m_p$ | $\rho/m_p$ |
| $N_{\rm HI}$ | $(1 - x)\rho/m_p$ | 0 |
| $P$ | $(1 + x)\rho k_BT/m_p$ | $2\rho k_BT/m_p$ |
| 单位质量的焓（热部分） | $\frac{\gamma}{\gamma-1}(1 + x)k_BT/m_p$ | $\frac{2\gamma}{\gamma-1}k_BT/m_p$（$= 5k_BT/m_p$） |
| 单位质量的电离能 | $x\chi_{\rm H}/m_p$，随流体元变 | $\chi_{\rm H}/m_p$，常数 |
| 电离能项 (8.13) | $(\chi_{\rm H}/m_p)\,\rho\,Dx/Dt \neq 0$ | 0 |
| $x$ 由什么决定 | Saha 方程 | 不需要 |
| 热传导系数 | $\kappa_e + \kappa_n$（`mixture_conductivity`） | $\kappa_0T^{5/2}$ |
| 辐射 | release 中没有 | $N_eN_i\Lambda_R(T)$ |

**完全电离时为什么严格为零。** $x \equiv 1$ 时 $\partial x/\partial t$ 和 $\partial x/\partial s$ 都为零，(8.13) 严格为零，连定常都不需要。8.5 第 3 步的论证（$\rho u$ 是常数，所以 $\rho u\,\chi_{\rm H}/m_p$ 是常数，导数为零）只是它在定常情况下的特例。

**色球里为什么不为零。** release 输出（`outputs/model_column/godunov_release/prod_godunov.txt.gamma_diag` 的最后一帧，t = 100 s，列 `T` 和 `x_eq`）中的电离度：

| 高度 | $T$ | $x$ |
|---:|---:|---:|
| 1601 km | 6 631 K | 0.27 |
| 1933 km | 6 665 K | 0.49 |
| 2123 km | 6 721 K | 0.64 |
| 2136 km | 6 974 K | 0.81 |
| 2142 km | 7 735 K | 0.98 |
| 2148 km 以上 | ≥ 13 800 K | 1.00 |

$Dx/Dt$ 的两部分在这里都不为零：

- **$u\,\partial x/\partial s \neq 0$**：蒸发的气体往上走，进入电离度更高的区域，必须在路上被电离。主要发生在 2120–2145 km 这一薄层，$x$ 从 0.64 升到 1。
- **$\partial x/\partial t \neq 0$**：柱子在被加热、在收缩，同一高度的电离度随时间变。

另外色球不是定常的，$\rho u$ 也不是常数：同一帧里 $\rho u$ 在柱子中从 1.7×10⁻¹¹ 变到 9.7×10⁻¹² kg m⁻² s⁻¹。所以“常数求导为零”的特例论证在这里也不成立。

**量级：这一项在色球里是主项。** 取 release 在 4000 s 时的 $\rho u$ = 2.7×10⁻¹⁰ kg m⁻² s⁻¹。把这股气体从柱底的 $x \approx 0.27$ 电离到 1，需要 $\rho u\,\chi_{\rm H}(1 - x)/m_p \approx 0.26$ W/m²；完全从中性电离则需要 0.35 W/m²。同一时刻，从上面传进柱子的热流是 0.53 W/m²（7.1），22 kK 处的焓通量 $\rho u\cdot5k_BT_{\rm ch}/m_p$ 约 0.24 W/m²。电离消耗与它们同一量级。这只是按定常估算的量级，因为柱子并不定常。所以传进色球的热有相当一部分用来电离上升的气体，去掉这一项，色球的能量账会明显出错。

**和接口位置的关系。** 电离几乎全部发生在柱子内部 2120–2145 km、6.7–14 kK 这一层。我们的接口在 22 kK，位于这一层之上，所以 TR 里 $x \equiv 1$，电离能项为零。SWMF 的 TR 底在 1 万 K，正好落在电离过程中间，所以它的表必须在底部扣掉 13.6 eV。柱子本身不需要任何改动：release 的 $E$ 里本来就含有电离能，求解器会自动计入 (8.13)。

## 9. AWSoM-R 的压强是怎么定出来的

本节按第 8 节的方式，从流体方程出发，说明 AWSoM-R 怎样定出压强。依据是 AWSoM-R 论文（Sokolov et al. 2021）第 2.2 节的式 (13)–(22)，并对照了 SWMF 代码（出处见 9.7）。没有运行 SWMF。符号沿用 8.3（已和论文统一）。唯一要注意的是 $T_{\rm ch}$：AWSoM-R 取 1 万 K，第 8 节取 22 kK。

### 9.1 各方程适用的区域

```
  区域                              在这里用的方程                     怎么解
  ─────────────────────────────────────────────────────────────────────────────────────
  三维日冕（AWSoM-R 的 MHD 网格）     不在本节推导                       数值，提供底部格点的温度
  ─── 三维区域的内边界 R = R_b ─────────────────────────────────────────────────────────
  thread 区域：沿磁力线的一维段         能量方程（定 T）+ 静力平衡（定 P）    数值，一维
  ─── TR 顶：T = T_TR ──────────────────────────────────────────────────────────────────
  TR 区域：厚度 L_TR                  和 8.5 相同的化简 → (9.1)、(9.2)     解析
  ─── TR 底：R = R☉，T = T_ch = 1 万 K ──────────────────────────────────────────────────
  （AWSoM-R 没有色球模型）
```

- **三维日冕。** AWSoM-R 的三维网格从 $R_b$ 开始，不延伸到太阳表面。它把内边界格点的温度交给下面的 thread，再从 thread 拿回压强和密度。
- **thread 区域。** 从三维区域的每个内边界格点出发，沿磁力线往下追踪到 TR 顶，得到一条一维的线。这里数值求解温度和压强。
- **TR 区域。** thread 最下面的一小段，从 $R_\odot$ 到 TR 顶。这里不解方程，直接用解析公式。
- **两个接口。** TR 顶：TR 和 thread 共用温度 $T_{\rm TR}$、压强 $P_{\rm TR}$ 和传导热流。thread 顶（$R_b$）：三维区域把温度交给 thread，thread 把压强和密度交给三维区域。

和第 8 节相比，**TR 的位置和作用相同，但 TR 下面没有色球，上面多了一段 thread 和三维日冕。**

### 9.2 原始方程

TR 和 thread 两个区域用的都是 8.4 的方程 (8.1)–(8.3)，但 AWSoM-R 的 $E$ 里没有电离能项。AWSoM-R 在 thread 上分开解电子和离子的温度，加热项 $Q_{\rm heat}$ 是 Alfvén 波的耗散 $\Gamma_-w_- + \Gamma_+w_+$；在 TR 里两种温度取相等。本节只关心压强怎么定，所以合成一个温度来写，这不影响结论。

### 9.3 TR 区域：假设和化简

AWSoM-R 在 TR 里的化简和 8.5 基本相同：

1. **定常。**
2. **$B$ 不变（截面不变）。**
3. **TR 内压强处处相同，$\{N_ik_BT\}$ 为常数。** 论文的理由是：TR 里温度变化的尺度远小于重力的压强标高。这和 8.5 第 5 步完全相同。
4. **TR 内没有加热，$Q_{\rm heat} = 0$。** 和 8.5 第 6 步相同。

有两处和第 8 节不同：

5. **TR 内没有流动，$\rho u = 0$。** 第 8 节保留了 $\rho u$，AWSoM-R 在 TR 里取零（论文式 (19) 只保留传导和辐射两项）。
6. **TR 底在 $T_{\rm ch}$ = 1 万 K，那里的传导热流为零，$q_{\rm ch} = 0$。** 论文的说法是：TR 只由日冕传下来的热加热，TR 底就定义为这股热流降到零的地方。第 8 节的底部在 22 kK，热流取柱子算出的 $q_{\rm ch}$。

在 1 万 K 处氢还没有完全电离，所以 8.9 的电离能项一般不为零。但它正比于 $\rho u$，而 AWSoM-R 取 $\rho u = 0$，所以这一项也消失了。

在这些假设下，(8.7) 只剩辐射一项，就是论文的式 (20)：

$$
\frac{d(q^2)}{dT} = \frac{\kappa_0\,P_{\rm TR}^2}{2k_B^2}\,\sqrt{T}\,\Lambda_R(T),\qquad q(T_{\rm ch}) = 0
$$

它可以直接积分，得到 $q(T) = \{N_ik_BT\}_{\rm TR}\,U_{\rm heat}(T)$。再代入厚度条件 (8.8)，得到论文的式 (21)、(22)：

$$
\{N_ik_BT\}_{\rm TR} = \frac{P_{\rm TR}}{2} = \frac{1}{L_{\rm TR}}\int_{T_{\rm ch}}^{T_{\rm TR}}\frac{\kappa_0\,T^{5/2}}{U_{\rm heat}(T)}\,dT \tag{9.1}
$$

$$
\kappa_0T_{\rm TR}^{5/2}\left(\frac{\partial T}{\partial s}\right)_{T = T_{\rm TR}} = q_{\rm TR} = \{N_ik_BT\}_{\rm TR}\,U_{\rm heat}(T_{\rm TR}) \tag{9.2}
$$

(9.1) 就是我们的 (8.10)，只是积分下限 $T_{\rm ch}$ 从 22 kK 换成了 1 万 K。(9.2) 是 TR 顶从上面吸收的热流，也就是这个 TR 在压强 $P_{\rm TR}$ 下能辐射掉的热量。

**两式右边都只依赖 $T_{\rm TR}$ 和 $L_{\rm TR}$。** 第 8 节在单柱时直接给定 $T_{\rm TR}$；AWSoM-R 不给定 $T_{\rm TR}$，而是用 thread 把它解出来（9.4）。这是两者最主要的区别。

$L_{\rm TR}$ 在 AWSoM-R 里也不是物理量。论文取约 1 Mm；代码里它是沿磁力线往下追踪时最下面两步的长度，由一个数值参数（步长）决定，在 1.4–2.8 Mm 之间，每条磁力线不同。

### 9.4 thread 区域：先定温度，再定压强

**能量方程定温度。** thread 上的能量方程是论文的式 (15)/(18)，也是从 (8.3) 化简来的，保留了加热 $Q_{\rm heat}$、辐射、热传导，以及三维区域流下来或流上去的焓通量。它对温度是二阶方程，需要两端各一个条件：

- **上端（三维区域的内边界 $R_b$）：** 温度等于三维格点的温度（论文 2.2.4 节：$T_{\rm TFLM} = T_{\rm GCM}$）。
- **下端（TR 顶）：** thread 往下送进 TR 的传导热流，必须等于 (9.2) 给出的 TR 能吸收的热流。

这个下端条件既不固定温度，也不固定温度梯度，而是把两者联系起来（论文原话：“set neither temperature nor its gradient”）。$T_{\rm TR}$ 因此不是输入，而是和整条 thread 上的温度分布一起解出来的。

物理图像是一个自我调节：日冕加热得越多，往下传的热越多；TR 要吸收更多的热，就需要更高的 $T_{\rm TR}$。由 (9.1)，$T_{\rm TR}$ 升高，$P_{\rm TR}$ 也升高（大致随 $T_{\rm TR}^3$）；压强高，TR 的密度就高，辐射也更强，正好把多送下来的热辐射掉。

**静力平衡定压强。** 解出 $T_{\rm TR}$ 后，由 (9.1) 得到 $P_{\rm TR}$。thread 上的动量方程 (8.2) 取定常、去掉动压（同 8.5 第 5 步），但**保留重力**，就是论文的式 (14)：

$$
\frac{\partial P}{\partial s} = -\rho g,\qquad \rho = \frac{m_pP}{2k_BT}
\quad\Rightarrow\quad
P(s) = P_{\rm TR}\exp\!\left(-\int_{\rm TR\,顶}^{s}\frac{m_pg}{2k_BT}\,ds'\right) \tag{9.3}
$$

（论文里重力写成 $GM_\odot/R^2$ 并乘以磁场的径向分量 $b_R$，这里简写为 $g$。）从 TR 顶一直积分到 thread 顶，得到的压强（和对应的密度）就交给三维区域，作为它内边界的值。

### 9.5 压强的完整链条

```
三维格点的温度
   │  thread 上的能量方程，下端用 (9.2) 的热流条件
   ▼
T_TR（TR 顶温度）
   │  (9.1)，还需要 L_TR
   ▼
P_TR（TR 压强）
   │  (9.3)，沿 thread 静力平衡往上推
   ▼
三维区域内边界的压强和密度
```

| 量 | 固定还是算出 | 怎么来 |
|---|---|---|
| $T_{\rm ch}$ = 1 万 K | 固定 | 假设：TR 底的温度 |
| $q_{\rm ch}$ = 0 | 固定 | 假设：TR 底就是热流降到零的地方 |
| TR 内的 $\rho u$ = 0 | 固定 | 假设 |
| $L_{\rm TR}$ | 几何量，1.4–2.8 Mm | 追踪磁力线的步长（数值参数） |
| $T_{\rm TR}$ | 算出，每步更新 | thread 能量方程 + (9.2) |
| $P_{\rm TR}$ | 算出 | (9.1) |
| thread 上和三维边界的压强 | 算出 | (9.3) |

链条里唯一写死的温度是 $T_{\rm ch}$ = 1 万 K；按第 4 节和 7.4，它对压强几乎没有影响。压强的大小由 $T_{\rm TR}$（物理，由日冕决定）和 $L_{\rm TR}$（几何，由数值参数决定）共同决定，并且与 $L_{\rm TR}$ 成反比。

### 9.6 和第 8 节的对比

| | AWSoM-R | 第 8 节推荐版本 |
|---|---|---|
| TR 底温度 $T_{\rm ch}$ | 1 万 K | 22 kK |
| TR 底的传导热流 $q_{\rm ch}$ | 0 | 柱子算出的值 |
| TR 里的流动 $\rho u$ | 0 | 柱子算出的值 |
| TR 里的电离能项 | 因 $\rho u = 0$ 而为零 | 因完全电离而严格为零（8.9） |
| $T_{\rm TR}$ | 由 thread 解出 | 单柱：外部给定；耦合：取 AWSoM-R 的值 |
| $L_{\rm TR}$ | 追踪几何，1.4–2.8 Mm | 单柱：1.5 Mm；耦合：取 AWSoM-R 的值 |
| 压强公式 | (9.1) | (8.9)；$\rho u = 0$、$q_{\rm ch} = 0$ 时就是 (8.10) |
| $P_{\rm TR}$ 放在哪 | TR 顶，再沿 thread 往上推 | TR 底，即我们的 ghost cell |
| TR 下面 | 没有模型 | 我们的色球柱子 |

**两边会不会冲突。** 代入同样的 $T_{\rm TR}$ 和 $L_{\rm TR}$，两个公式只差三处：

- 积分下限 $T_{\rm ch}$：约 1 %（7.4）；
- 底部热流 $q_{\rm ch}$：约 10⁻⁴（8.7）；
- 蒸发 $\rho u$：release 下约 −1.5 %（8.8）。

两边又都假设 TR 里压强处处相同，所以 AWSoM-R 放在 TR 顶的数，和我们放在 TR 底的数，在这个假设下应当相等，接口上不会有压强跳变。耦合时，如果两边各算各的，会留下上面这百分之几的差别。避免它的办法是只让一边算 $P_{\rm TR}$，另一边直接使用结果；用我们的公式（从 22 kK 起算，计入柱子的蒸发通量）更完整。

**两边共有的误差。** “TR 里压强处处相同”忽略了重力。若按静力平衡，TR 顶的压强比底部低：$T_{\rm TR}$ 在 30 万到 100 万 K、$L_{\rm TR}$ 在 1.4–2.8 Mm 时，$\ln P$ 下降 0.04–0.27，即 4–27 %，$T_{\rm TR}$ 越低、$L_{\rm TR}$ 越长，压降越大（离线估算，脚本没有放进仓库）。这个误差两边一样，所以不造成两者之间的冲突，但它说明 TR 压强的绝对值只准到大约这个程度。如果以后只在一边加上 TR 里的重力，就必须决定在 TR 顶还是 TR 底对齐，那时才会出现冲突。
