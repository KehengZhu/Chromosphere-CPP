Detailed Description

PFSS field-line scenario driven by a tabulated field-line data file.

PFSS field-line scenario.

Initializes the grid from a tabulated data file produced by util/extract_field_line.py (PFSS extrapolation of a synoptic magnetogram, traced from a chosen footpoint to the top of the chromospheric domain).

File format: see scenarios/data_file_parser.hpp.

Boundary update delegates to apply_open_bcs (scenario.hpp): reflecting wall at the inner face, zero-gradient outflow at the outer face. The [GHOSTS] section of the data file is therefore only used to seed the pre-step ghost state in pfss_ic; the first update_bc call replaces it.
