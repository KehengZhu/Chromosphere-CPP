1/*!
2 * @file scenarios/model_c7.hpp
3 * @brief Model C7 quiet-Sun chromosphere scenario and the shared C7 atmosphere library.
4 * @ingroup scenarios
5 *
6 * Model C7 chromosphere scenario (writeup Table 1).
7 *
8 * `model_c7_ic` configures the Grid's cell-centered fields (ds_i, B, boundary
9 * buffers) and returns the initial conserved-state vector. `model_c7_update_bc`
10 * applies the model_c7-specific boundary conditions:
11 *
12 * * Outer face (lower TR, h ≈ 2153 km) — two modes. In BOTH of them the coronal
13 * heat enters as the imposed Stage-D Neumann flux q(T), never as a Dirichlet
14 * hot wall: on this coarse grid a fixed coronal ghost temperature would
15 * over-conduct (κ_e ∝ T^{5/2}) and over-pressurize the top cell.
16 * default (tr_jump_bc=false): fixed lower-TR reservoir (RTV 1978) — ρ,T
17 * Neumann (continuous pressure across the constant-pressure TR base),
18 * V,U Mach-capped outflow (U = V).
19 * "New explanation" (tr_jump_bc=true): hydrostatic ghost pressure (centered
20 * HSE ⇒ V = 0 is a boundary fixed point, no boundary downflow), ghost
21 * temperature CONTINUOUS from the top cell (T_g0 = a·T_top,
22 * T_g1 = b·T_g0, with a = b = 1 by default so there is no jump —
23 * C7_TJUMP_A / C7_TJUMP_B are an experimentation lever only), and an EOS
24 * ghost density at that (p, T); V,U Mach-capped outflow. The ghost
25 * temperature sets the EOS density and the hydro flux; it does NOT drive
26 * conduction.
27 *
28 * * Inner face — photospheric discrete-HSE V=U=0 reservoir (Pandey 2024):
29 * ρ_i, ρ_n → Dirichlet (pinned at the C7 base captured in IC)
30 * p_i, p_n → hydrostatic ghost p = p_0 + ρ_0 g Δs
31 * V, U → 0 (exact momentum fixed point)
32 */

44/// Build the Model C7 initial conserved-state vector and populate the Grid's
45/// cell sizes, B-field, gravity potential, and boundary buffers.
46///
47/// `extended` selects the domain top: false (default) ⇒ the standard column to
48/// h ≈ 2.153 Mm (T ≈ 23 kK, lower TR) with the RTV-estimated coronal flux q(T) —
49/// the baseline model_c7 / model_flare use this. true ⇒ extend through the real
50/// Avrett & Loeser (2008) Table 26 rows up to h ≈ 2.628 Mm (T ≈ 0.29 MK, upper
51/// TR), with q(T) computed self-consistently from C7's own conductive gradient
52/// at the new top — the corona-as-boundary configuration for gentle
53/// conduction-driven evaporation (docs/gentle_evaporation_plan.md v2; model_gentle).
54///
55/// `tr_jump_bc` selects the upper boundary closure. false (default) ⇒ the
56/// Mach-capped RTV reservoir (model_flare / analytic_canopy / model_gentle keep
57/// this). true ⇒ the "New explanation" upper BC
58/// (docs/gentle_evaporation_downflow.md): well-balanced reconstruction +
59/// hydrostatic ghost pressure + a ghost temperature extrapolated continuously
60/// from the top cell + EOS ghost density — set by the bare `model_c7` scenario.
61/// Both modes keep the imposed Neumann flux q(T) as the conductive driver;
62/// `tr_jump_bc` does NOT switch it off. The ghost-temperature factors are
63/// env-tunable but default to C7_TJUMP_A = C7_TJUMP_B = 1, i.e. no jump.
64Vec model_c7_ic(Grid& grid, bool extended = false, bool tr_jump_bc = false);

66/// Sample the complete Model C7 atmosphere (Avrett & Loeser 2008 Table 26,
67/// photosphere h ≈ −10 km → corona h ≈ 68 Mm) at height `h_km`: temperature `T`
68/// linearly, electron density `n_e` and neutral-hydrogen density `n_HI`
69/// log-linearly. Concatenates the photosphere rows (h < 1003 km, absent from the
70/// model_c7 chromosphere/corona table) with MODEL_C7; clamps to the table ends.
71/// Used by model_column's corona testbed to set a realistic frozen ionization
72/// profile (so the corona is ionized and conducts via Spitzer κ_e).
73void c7_full_profile(float h_km, float& T, float& n_e, float& n_HI);
74
75/// Shape-preserving C1 interpolation of the complete Model C7 temperature
76/// table. Unlike c7_full_profile's historical piecewise-linear temperature,
77/// this has a continuous dT/dh and therefore does not seed knot-scale jumps in
78/// conductive heat flux. Used only by gamma-table model_column initialization;
79/// fixed-gamma scenarios retain their existing interpolation exactly.
80double c7_full_temperature_pchip(double h_km);

82/// Route-B photoionization closure (docs/photoionization_c7_inversion_plan.md,
83/// writeup §3.1): given cell-centered (T, n_i, n_n) and heights [km], return the
84/// per-cell photoionization rate P_phot that makes the profile a fixed point of
85/// the active Stage-E ionization network, blended above ~1500 km to the frozen
86/// FAL-C rate (Chae 2021). Shared by model_c7_ic and model_column_ic.
87Vec c7_route_b_photoionization(const Grid& grid, const Vec& T_c,
88 const Vec& ni_c, const Vec& nn_c,
89 const Vec& h_cell);

91/// Refresh ghost cells. Applies the coronal q(T) time ramp when one is
92/// configured, lays down the default ghost layer with `apply_open_bcs`, then
93/// OVERWRITES both faces: the outer face with whichever of the two lower-TR
94/// closures `tr_jump_bc` selected, and the inner face with the photospheric
95/// discrete-HSE reservoir (Dirichlet ρ_i and ρ_n pinned at the C7 base captured
96/// in the IC, hydrostatic ghost pressures, V = U = 0).
97/// See the file-level comment above for the full BC table.
98void model_c7_update_bc(Grid& grid, const Vec& xn);
