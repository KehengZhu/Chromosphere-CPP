Detailed Description

The chromo_main command-line program, its step-cap and snapshot scheduling helpers, and the files it writes.

The driver owns no physics. See Configuration reference for the full command-line and environment reference and Output file formats for the output file layouts.

Enumeration Type Documentation

◆ StepCapSource

enum class chromosphere::StepCapSource
strong

Which rule produced the step cap in force.

select_step_cap() sets exactly one of these, and the run banner prints its step_cap_source_name() so a finished run records why it was allowed to stop.

Enumerator
Explicit 

CHROMO_STEP_CAP.

LegacyTimeMult 

max(10000, 10000*time_mult), no CHROMO_T_END

EndTime 

CHROMO_T_END set, no explicit cap -> unbounded.

Invalid 

CHROMO_STEP_CAP present but unparseable or non-positive; see StepCapSelection::error.

Enumerator
