1/*!
2 * @file scenarios/model_column.hpp
3 * @brief model_column (RELEASE) and model_gentle (historical two-fluid) — the
4 * field-aligned chromosphere-to-corona column.
5 * @ingroup scenarios
6 *
7 * model_column — the field-aligned chromosphere→corona column. One IC/BC
8 * implementation, TWO scenarios that never cross solvers:
9 *
10 * * `model_column` — the DEFAULT and the RELEASE scenario. It always loads
11 * the production Gamma1 table, so it always runs the single-fluid
12 * equilibrium-mixture solver (src/single_fluid/) with the state
13 * U = (rho, rho u, E) and the timestep
14 * U^n -> MUSCL/Roe hydro -> U* -> implicit physical conduction -> U^{n+1}.
15 * Every historical two-fluid knob listed below is REJECTED outright in this
16 * mode, so `model_column` names exactly one production model.
17 *
18 * * `model_gentle` — the HISTORICAL two-fluid research preset. It never loads
19 * a Gamma1 table, so it always runs the seven-row two-fluid solver
20 * (src/two_fluid/) with a fixed adiabatic index, finite-rate ionization, a
21 * radiative sink, TRAC and the mesh-scaled artificial conduction term.
22 *
23 * A single straight field line (B = 1, gravity on) initialized from the real
24 * Model C7 atmosphere (Avrett & Loeser 2008, Table 26; via c7_full_profile in
25 * model_c7.cpp), driven to conduction-driven ("gentle", Antiochos & Sturrock
26 * 1978) evaporation.
27 *
28 * The numerical scheme is the well-balanced, high-order configuration validated in
29 * docs/gentle_evaporation_downflow.md (the "bestwb" set) — ALWAYS ON here, no toggles:
30 * - well-balanced explicit reconstruction (φ_g-consistent shifted pressures),
31 * - log-space MUSCL reconstruction of the exponentially-stratified slots,
32 * - the asymmetric MC3/Koren limiter (β = 2),
33 * - equilibrium-reference ("δ-form") well-balancing (V = 0 exact for any strat.),
34 * - inner (photospheric) discrete-HSE reservoir well-balanced through BOTH ghosts,
35 * density included (ρ ∝ p at T₀) so V = 0 is an exact fixed point for mass too.
36 * The release additionally uses the mixture Roe characteristic flux and the
37 * (ln rho, u, ln p) primitive set. Together these hold a hydrostatic column at
38 * V ≈ 0 to round-off, so any residual flow is physical (conduction-driven
39 * evaporation), not truncation drainage.
40 *
41 * IC: the C7 temperature and ionization FRACTION with the total density re-integrated
42 * hydrostatically from the base (clean V ≈ 0 start).
43 *
44 * Env knobs valid in BOTH modes (numerics are fixed; only physics is tunable):
45 * ISO_NS grid cells (release preset: 500 coarse-equivalent)
46 * ISO_H_BASE domain base height [km] (release preset: 1600)
47 * ISO_DH domain height span [km] (release preset: 553)
48 * ISO_HEAT_FLUX 0 = Stage-1 relaxation (conduction off) / 1 = conduction on
49 * ISO_RELAX_TIME Stage-1 adiabatic relaxation phase length [s] (default 0)
50 * ISO_TJUMP_A/_B top ghost-T jump factors a, b (default 1)
51 * ISO_T_TOP absolute imposed top-boundary temperature [K] (release: 22000)
52 * ISO_HYDRO_T_DECOUPLE hydro ghost T free-floats; conduction keeps the fixed
53 * PHYSICAL-FACE wall (release preset: 1)
54 * ISO_VCAP outer outflow Mach cap (default 0.1)
55 * ISO_INNER_T_NEUMANN conduction lower BC: 0 = Dirichlet (default) / 1 = Neumann
56 * ISO_REFINE_* static local mesh refinement (scenarios/mesh.hpp)
57 *
58 * HISTORICAL two-fluid-only knobs — rejected by the release scenario:
59 * ISO_GAMMA fixed adiabatic index of the two-fluid solver
60 * ISO_TWO_FLUID evolve ion & neutral as separate fluids
61 * ISO_IONIZATION Stage-E ionization/recombination network
62 * ISO_COOLING optically-thick + thin radiative sink (Stage R)
63 * ISO_CORONA / ISO_CORONA_TOP_KM extend into a resolved ~1 MK corona
64 * ISO_TRAC / _TCHROM / _TCMAXFRAC TRAC TR-broadening
65 * ISO_QFLUX / _ENHANCE / _T_ON / _RAMP / _0 imposed coronal q(T) flux + ramp
66 * ISO_CHEAT / _E0 / _TMAX_MK / _SH_FRAC / _S0_MM / _ENHANCE / _T_ON / _RAMP
67 * ambient volumetric coronal heating H(s) + ramp
68 * ISO_TBOOST / _TC / _W one-time IC coronal superheat
69 * ISO_NUMERICAL_DIFFUSIVITY_MULT mesh-scaled artificial conduction
70 *
71 * Reference-only numerical overrides (regression/comparison, never production):
72 * ISO_RIEMANN=rusanov, ISO_RECONSTRUCTION=lnrho-v-lnt, ISO_LIMITER
73 */

85/// Initial condition shared by `model_column` (release) and `model_gentle`
86/// (historical two-fluid).
87///
88/// Loads the `GAMMA_TABLE` when one is given — a loaded Gamma1 table is what
89/// selects the single-fluid release solver, an empty one leaves the two-fluid
90/// solver — and in release mode REJECTS every historical two-fluid knob listed
91/// in the file header, so a release run cannot be silently reconfigured. Then it
92/// builds the mesh (optionally statically refined, which may resize the Grid),
93/// sets the field-line geometry and gravity, samples the Model C7 temperature
94/// and ionization fraction, re-integrates the density hydrostatically from the
95/// base for a clean V ≈ 0 start, fills both ghost layers via
96/// model_column_update_bc(), and returns the initial conserved state — three
97/// `mix::` rows in release mode, seven `cons::` rows in two-fluid mode.
98///
99/// The release leg is REFERENCE-FREE: it leaves `Grid::eq_wb` false and stores
100/// no frozen equilibrium state. Only the two-fluid leg sets eq_wb and freezes
101/// this IC as `Grid::eq_state`.
102Vec model_column_ic(Grid& grid);
103
104/// Per-step boundary refresh for both legs of the scenario.
105///
106/// Decodes the top and base interior cells with whichever state convention is
107/// active (mixture decode for the release, cons2prim algebra for the two-fluid
108/// path) and rewrites the two outer and two inner ghost layers:
109///
110/// * outer — subsonic outflow: a hydrostatic ghost ladder anchored on the fixed
111/// reservoir back-pressure `kOuterPRef` (captured once, the single externally
112/// imposed condition of a subsonic outflow face), the top-cell velocity
113/// extrapolated but Mach-capped at `ISO_VCAP` × c_s, and — in the release
114/// preset, where the hydro ghost temperature free-floats with the top cell —
115/// the 22,000 K thermal datum handed to the conduction stage at the PHYSICAL
116/// outer face instead;
117/// * inner — the quasi-static stratified reservoir at the 1600 km truncation
118/// temperature `kInnerTRef` with V = 0, laid out on a second-order
119/// (trapezoidal, EOS-closed) ghost ladder.
120///
121/// It also advances the time-dependent two-fluid drivers (the imposed q(T) flux
122/// ramp and the coronal-heating ramp), which are inactive in release mode.
123void model_column_update_bc(Grid& grid, const Vec& xn);
