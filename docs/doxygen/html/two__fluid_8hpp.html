Detailed Description

HISTORICAL two-fluid / multi-temperature / finite-rate-ionization research solver API (seven-row carrier state).

NOT the release path.

two_fluid.hpp — the HISTORICAL two-fluid / multi-temperature / finite-rate-ionization research solver. NOT the release path.

The conserved state is the seven-row ion/neutral/electron carrier vector cons:: declared in chromosphere.hpp. Every entry point below rejects a Grid that carries a Gamma1 table, i.e. a Grid configured for the single-fluid release solver in single_fluid/mixture.hpp.

Dependency direction: this header depends only on the shared infrastructure in chromosphere.hpp. It never includes or calls the single-fluid solver, and the single-fluid solver never includes or calls anything declared here.
