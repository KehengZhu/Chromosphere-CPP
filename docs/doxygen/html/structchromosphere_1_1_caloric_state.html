Detailed Description

Every caloric quantity of the pure-H equilibrium closure at one (rho, T), produced by a SINGLE Saha evaluation.

Each field is computed with exactly the expression of the standalone function it replaces, so a caller that used to invoke saha_ionization_fraction_n_h, equilibrium_internal_energy and equilibrium_heat_capacity separately gets bit-for-bit the same values.
