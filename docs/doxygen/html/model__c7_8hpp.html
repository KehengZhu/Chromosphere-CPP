Detailed Description

Model C7 quiet-Sun chromosphere scenario and the shared C7 atmosphere library.

Model C7 chromosphere scenario (writeup Table 1).

model_c7_ic configures the Grid's cell-centered fields (ds_i, B, boundary buffers) and returns the initial conserved-state vector. model_c7_update_bc applies the model_c7-specific boundary conditions:

  • Outer face (lower TR, h ≈ 2153 km) — two modes. In BOTH of them the coronal heat enters as the imposed Stage-D Neumann flux q(T), never as a Dirichlet hot wall: on this coarse grid a fixed coronal ghost temperature would over-conduct (κ_e ∝ T^{5/2}) and over-pressurize the top cell. default (tr_jump_bc=false): fixed lower-TR reservoir (RTV 1978) — ρ,T Neumann (continuous pressure across the constant-pressure TR base), V,U Mach-capped outflow (U = V). "New explanation" (tr_jump_bc=true): hydrostatic ghost pressure (centered HSE ⇒ V = 0 is a boundary fixed point, no boundary downflow), ghost temperature CONTINUOUS from the top cell (T_g0 = a·T_top, T_g1 = b·T_g0, with a = b = 1 by default so there is no jump — C7_TJUMP_A / C7_TJUMP_B are an experimentation lever only), and an EOS ghost density at that (p, T); V,U Mach-capped outflow. The ghost temperature sets the EOS density and the hydro flux; it does NOT drive conduction.
  • Inner face — photospheric discrete-HSE V=U=0 reservoir (Pandey 2024): ρ_i, ρ_n → Dirichlet (pinned at the C7 base captured in IC) p_i, p_n → hydrostatic ghost p = p_0 + ρ_0 g Δs V, U → 0 (exact momentum fixed point)
