Detailed Description

One fully parsed scenario data file: the [META] scalars, the ns per-cell [CELLS] columns, and the four [GHOSTS] rows, in SI units throughout.

This is a faithful transcription of the file, not a Grid: the consumer (pfss_ic) copies the geometry columns into the Grid and builds the conserved state from (n_e, n_n, T). Vector members are sized only after a successful parse_scenario_data_file().
