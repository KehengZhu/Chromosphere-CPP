9 * The project carries TWO solvers over one shared field-aligned mesh, each in
10 * its own source directory:
11 *
12 * * the RELEASE solver, `src/single_fluid/` (`single_fluid/mixture.hpp`): a
13 * single-fluid equilibrium-mixture model whose conserved state is the
14 * three-component vector U = (rho, rho u, E). This is what the canonical
15 * `model_column` production configuration advances;
16 *
17 * * the HISTORICAL two-fluid / multi-temperature / finite-rate-ionization

19 * conserved state is the seven-row ion/neutral/electron carrier vector.

390/// The object that owns all solver state: mesh geometry, the prescribed magnetic
391/// field, gravity, the physical constants, every runtime toggle, the ghost
392/// buffers of both solvers, and the reusable scratch workspaces.
393///
394/// The caller owns the Grid. Solver functions take `const Grid&`, or `Grid&` when
395/// they write a scratch buffer, so several Grids can coexist and every test can
396/// construct its own — there is no global mutable state anywhere in the project.

398/// Usage is always the same three steps: init() allocates for a cell count, the
399/// scenario fills the geometry (and may resize() when it generates a locally
400/// refined mesh), and broadcast() derives the packed and static-mesh caches from
401/// it. Anything that edits `ds_i`, `B_i`, `B_imh`, `B_iph` or `dinvB_ds_i`
402/// afterwards must call broadcast() again.

464 /// is p = (γ−1)[E − ½ρv² − ρφ] and the heat capacity per volume is C = nk/(γ−1).
