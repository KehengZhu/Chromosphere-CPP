Detailed Description

RAII wall-clock timer for one ProfileRegion: it samples a steady_clock stamp at construction and, at destruction, adds the elapsed seconds to that region's bucket for the calling thread.

Whether profiling is on is latched at construction, so toggling it mid-scope cannot produce a one-sided measurement. Non-copyable, and a no-op beyond one branch when profiling is off.
