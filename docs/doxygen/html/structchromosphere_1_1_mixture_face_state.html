Detailed Description

Fully decoded, on-manifold face state of the release solver.

Flux and wave-speed evaluation use these fields directly, so no temperature inversion is needed after the numerical flux.

◆ dp_deint_rho

double chromosphere::MixtureFaceState::dp_deint_rho

General-EOS pressure response at fixed total density: the partial derivative of p with respect to e_int at fixed rho, b = (dp/de_int)_rho [dimensionless].

It is evaluated from the same Saha closure as the ratio (dp/dT)_rho / (de_int/dT)_rho. This is distinct from Gamma1: Gamma1 fixes the isentropic acoustic speed, while b fixes the energy component of the Euler characteristic vectors.
