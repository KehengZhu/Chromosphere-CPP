Detailed Description

chromosphere::Grid — the object that owns all solver state — plus the two conserved-row index sets and the reusable scratch buffers.

There is no global mutable state. Solver functions take const Grid&, or Grid& when they write a scratch buffer, so several Grids can coexist and every test can construct its own.
